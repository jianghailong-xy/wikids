</Callout>

## The Text 课文

**CONDUCTOR:** Fares, please!
**MAN:** Trafalgar Square, please.
**CONDUCTOR:** I'm sorry, sir. **I can't change a ten-pound note. Haven't you got any small change?**
**MAN:** **I've got no small change,** I'm afraid.
**CONDUCTOR:** I'll ask some of the passengers.

**CONDUCTOR:** Have you any small change, sir?
**1st PASSENGER:** I'm sorry. **I've got none.**
**2nd PASSENGER:** **I haven't got any either.**

**CONDUCTOR:** Can you change this ten-pound note, madam?
**3rd PASSENGER:** I'm afraid I can't.
**4th PASSENGER:** **Neither can I.**

**CONDUCTOR:** I'm very sorry, sir. **You must get off the bus. None of our passengers can change this note.** They're all millionaires!
**TWO TRAMPS:** **Except us.**
**1st TRAMP:** **I've got some small change.**
**2nd TRAMP:** **So have I.**

## 课文注释 Notes on the text

<Callout type="info" title="7 个值得停下来嚼一嚼的点">
  1. **Fares, please!** — “请买票！”售票员招呼乘客买票的常用语。**fare** 指车费、车票钱。同型：*Tickets, please!*（请出示车票，L95）。
  2. **Trafalgar Square** — 特拉法加广场（伦敦市中心著名广场）。坐公交车报站名只需说地点名，意为“请给我一张到……的票”。
  3. **I've got no small change.** — “我没有零钱。”**no + 名词** 构成否定，语气比 *I haven't got any small change.* 更重。—— 两种说法都对，本课都出现了。**small change** = 零钱 / 硬币（不可数）。
  4. **I've got none.** — “我一点零钱也没有。”（一个子儿都没有）。**none** 是代词，= **not any** 或 **no + 前面提过的名词**，代替上文 *small change*。同型：*None of our passengers can change this note.*（我们的乘客中没人能换开这张钞票）。
  5. **Neither can I.** — “我也不能。”**neither** 引导的简略答语，表示**前面说过的否定情况也适用于后面的人**。语序铁律：**Neither + 助动词 / be 动词 + 主语**。否定接龙三步走：①起头的句子用否定（*I'm afraid I can't.*）→ ②听到否定 → ③接 *Neither + can/could/do/does/did/is/are/have/has + I/he/she/they.* —— 把助动词倒着装！
  6. **get off the bus** — “下车”。反义：**get on the bus**（上车）。*off* 是“离开 / 脱离”，*on* 是“在……上”。同型的 *get on/off* 也用于火车、飞机。
  7. **So have I.** — “我也有（零钱）。”**so** 引导的简略答语，表示**前面说过的肯定情况也适用于后面的人**——是 *Neither can I.* 的“肯定版”。语序铁律：**So + 助动词 / be 动词 + 主语**。肯定接龙三步走：①起头的句子用肯定（*I've got some small change.*）→ ②听到肯定 → ③接 *So + have/can/do/does/did/is/are + I/he/she/they.* —— 同样是“助动词倒着装”！
</Callout>

## 3. 关键句型：So / Neither 引导的简略答语

<Callout type="tip" title="一分钟回顾：肯定接龙用 So，否定接龙用 Neither——核心都是“助动词倒装”">
  本课的核心语法是**用 so 和 neither 表达“也……”**，省得把整句话重复一遍。规律非常整齐：

  | 起头的句子 | 接龙回应 | 规则 |
  |---|---|---|
  | **肯定句** *I've got some change.* | **So** have I.（我也有） | **So + 助动词 + 主语** |
  | **否定句** *I can't change that note.* | **Neither** can I.（我也不能） | **Neither + 助动词 + 主语** |

  关键：① 原句里用什么助动词 / be 动词，**so / neither 后面就用同一个**；② 不能用 *So I have* 或 *Neither I can*——语序一定是**助动词倒装在主语前面**。

  ### 肯定接龙（So ...）三步走

  ① 听到肯定句 → ② 抠出它的**助动词 / be 动词**（have / has / can / do / does / did / am / is / are）→ ③ 说 **So + 那个助动词 + 主语**。
  *I've got a ticket.* → **So have I.**（我也有）
  *She likes tea.* → **So do I.**（我也喜欢）
  *He can swim.* → **So can she.**（她也能）

  ### 否定接龙（Neither ...）三步走

  ① 听到否定句 → ② 抠出它的**助动词 / be 动词** → ③ 说 **Neither + 那个助动词 + 主语**。
  *I can't swim.* → **Neither can I.**（我也不能）
  *He doesn't smoke.* → **Neither do I.**（我也不抽）
  *She isn't tired.* → **Neither am I.**（我也不累）

  ### ⚠️ 4 个本课最容易踩的雷区

  1. **肯定用 So，否定用 Neither** —— 不能反过来。*I can't swim.* → *So can I.* ✗（肯定词 So 不该接否定句）。
  2. **语序必须是“So/Neither + 助动词 + 主语”**，不能写成 *So I have* 或 *Neither I can*——那是正常语序，不是“倒装接龙”。
  3. **助动词要跟原句一致**。原句说 *I can't ...* 就用 *Neither can ...*，不能换 *Neither do ...* 或 *Neither have ...*。
  4. **没有助动词的句子，接龙时要补 do / does / did**。*I like coffee.* → 原句没有助动词，接龙说 *So do I.*（补 do）。
</Callout>

## 4. 难点：have got 的否定与 none / no / any

<Callout type="info" title="本课同一句话“我没有零钱”用了三种说法——各有各的口气">
  本课围绕“有没有零钱”把 have got 的否定形式来了一遍全覆盖：

  | 说法 | 结构 | 语气 |
  |---|---|---|
  | **I've got no small change.** | have got + **no** + 名词 | 语气最重——“一分零钱都没有” |
  | **I've got none.** | have got + **none**（代词，代替上文名词）| 同上，但更短促 |
  | **I haven't got any small change.** | have **not** got + **any** + 名词 | 常规否定，中等语气 |

  ### 三个关键区别

  - **no + 名词** = not any + 名词。**no** 本身就是“零”，后面不能再加 not（*I haven't got no* ✗ 双重否定）。
  - **none** 是代词，**独立使用，后面不跟名词**：*I've got none.* ✓ / *I've got none small change.* ✗（none 后面跟名词需要 of：*none of our passengers*）。
  - **Either** 放在否定句句末，表示“也（不）”：*I haven't got any **either**.* = 我也没有（与前面否定句呼应）。

  ### ⚠️ 易错雷区

  - *I haven't got **no** change.* ✗ — 双重否定（haven't + no）
  - *I've got **none** small change.* ✗ — none 不能直接修饰名词，应改为 *I've got **no** small change.*
  - *I haven't got any **too**.* ✗ — 否定句句末“也”用 **either**，不用 too
</Callout>

## 9. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。本课对话人物众多——售票员的职业化语气、男乘客的无奈、流浪汉轻快的一句 *Except us* 要读出反差。重点练 *Neither can I.* 和 *So have I.* 的节奏——它们是脱口而出的简略句，两句之间几乎不换气。
  - **角色扮演**：合上课文，分饰售票员、男乘客、四位乘客、两个流浪汉，把整场对话从头演到尾。注意每个乘客拒绝时的不同说法——有人用 *none*、有人用 *any either*、有人用 *Neither can I.*、有人说 *I'm afraid I can't.*。
  - **复述 (retell)**：用 1 分钟用自己的话讲这个故事。**三步走**：起因（男士拿 10 英镑买票，售票员找不开）→ 经过（售票员问遍全车，没一个乘客能换开）→ 结局（两个流浪汉有零钱，全车最讽刺的瞬间）。
  - **接龙练习**：造 10 组“我说一句，你接一句”的口语练习——
    1. *I'm a student.* → **So am I.**
    2. *I can speak English.* → **So can I.**
    3. *I like coffee.* → **So do I.**
    4. *I went shopping yesterday.* → **So did I.**
    5. *I've got a car.* → **So have I.**
    6. *I'm not tired.* → **Neither am I.**
    7. *I can't swim.* → **Neither can I.**
    8. *I don't smoke.* → **Neither do I.**
    9. *I didn't go out last night.* → **Neither did I.**
    10. *I haven't got any money.* → **Neither have I.**
  - **造句迁移**：用今天学的 5 个本课结构造自己的句子——
    1. *I've got no ...* —— *I've got no time today.*
    2. *Haven't you got any ...?* —— *Haven't you got any water?*
    3. *Neither can I. / Neither do I. / Neither have I.* —— *She can't drive. Neither can I.*
    4. *So have I. / So do I. / So am I.* —— *He likes pizza. So do I.*
    5. *None of ...* —— *None of my friends can come to the party.*
  - **so 与 neither 的区分**：写 3 对“肯定 + 肯定接龙”和 3 对“否定 + 否定接龙”（共 12 句），确认每次选对了 So 还是 Neither，且助动词与原句保持一致。
  - **听写 (dictation)**：听录音，把整篇对话默写下来。写完对照原文用红笔圈出拼写/标点错误——本课难度上来了，对话长度和角色数量都大幅增加，是一次很好的耐力训练。
