## The Pattern Drill 句型操练

下面是本课 **6 组替换操练**——六家店铺，每家都有自己的商品。跟着图，把每句话大声念出来。模板句型只有两个：

> **I must go to the ... to get some ...**（我必须去……买一些……）
> **I need a lot of ... I haven't got much / many.**（我需要很多……我没多少了。）

### 1. GROCER'S 食品杂货店 — to get some GROCERIES

cheese（奶酪）

### 2. GREENGROCER'S 蔬菜水果店 — to get some FRUIT and VEGETABLES

pears（梨）· oranges（橙子）· bananas（香蕉）· beans（豆角）

### 3. BUTCHER'S 肉店 — to get some MEAT

beef（牛肉）· steak（牛排）· mince（肉馅）· chicken（鸡肉）

### 4. NEWSAGENT'S 报刊文具店 — to get some STATIONERY

glue（胶水）· envelopes（信封）· writing paper（信纸）· magazines（杂志）

### 5. BAKER'S 面包店 — to get some BREAD and CAKES

bread（面包）· cakes（蛋糕）

### 6. CHEMIST'S 药店 — to get some MEDICINE

aspirins（阿司匹林）· medicine（药）

## 课文注释 Notes

<Callout type="info" title="6 个值得停下来嚼一嚼的点">
  1. **must** — “必须、不得不”。情态动词，后面跟 **动词原形**，没有人称和数的变化。本课用它来表达“必须去某地做某事”：*I must go to the baker's.* / *She must go to the chemist's.* 否定式 *mustn't* 表示“绝对不可以 / 禁止”，与本课练习无关（本课说的“没有某物”用 *haven't got* 而不是 must 的否定）。

  2. **need** — “需要”。本课作实义动词，后面直接跟名词：*I need a lot of bread.* / *We need some meat.* 也可跟 *to do*：*I need to go to the shops.* ⚠️ 注意和 must 的分工：must 强调“必须”的主观义务感（*I must go*），need 强调“缺、需要”的客观事实（*I need bread*）。

  3. **haven't got much / many** — “没有多少”。这是英式英语表示“拥有量不多”的常用说法。*have got* = have（有），否定式为 *haven't got* 或 *hasn't got*。后面的量词取决于名词类型：
     - **much** + 不可数名词：*I haven't got much bread / butter / milk / beef / stationery / medicine.*
     - **many** + 可数名词复数：*I haven't got many eggs / envelopes / biscuits / magazines / bananas.*
     在否定句里 much 和 many 都常用；肯定句里常用 *a lot of*（本课的 *need a lot of ...*）。

  4. **店铺名称的 's 结构**：*grocer's / greengrocer's / butcher's / newsagent's / baker's / chemist's* —— 这些是 **名词所有格** 的省略形式，全称是 *grocer's shop*（食品杂货商的店）、*butcher's shop*（肉铺）等。口语里只说 's 就够了。读的时候，*grocer's* 里面的 's 要轻读 /z/。

  5. **to get** — 不定式表目的。*I must go to the grocer's to get some cheese.* 里的 **to get** = “为了买 / 为了取得”。这个 *to + 动词原形* 的结构告诉你“去那个地方的目的”。同型：*I went to the kitchen to get a glass of water.*（我去厨房拿杯水。）

  6. **stationery**（文具）是不可数名词，不能说 *a stationery* 或 *stationeries*。同理，*groceries*（食品杂货）通常用复数、作可数处理（*I must get some groceries*），但单件物品 cheese、butter 不可数。
</Callout>

## 3. 关键句型：must / need / have got / much vs many

<Callout type="tip" title="一分钟回顾：用 must 说「必须」、用 need 说「需要」、用 haven't got 说「缺货」">
  本课是第 79 课的句型操练场，把卡罗尔那张购物单里的三个武器反复练到熟：

  | 句型 | 用途 | 例子 |
  |---|---|---|
  | **I must go to ... + to get ...** | 说“必须去哪家店买什么” | *I must go to the butcher's to get some beef.* |
  | **I need a lot of ...** | 说“需要很多某物” | *They need a lot of bread.* |
  | **I haven't got much / many ...** | 说“某物剩得不多了” | *She hasn't got much butter. / We haven't got many eggs.* |

  ### ⚠️ 4 个本课最容易踩的雷区

  1. **must 后面永远跟动词原形**：*I must **go*** ✓ / *I must goes* ✗ / *I must to go* ✗。must 不加 s、不加 to、后面动词不变形。
  2. **much → 不可数 / many → 可数复数**：*much bread, much butter, much milk* ✓ / *many eggs, many magazines, many bananas* ✓。想一想：能不能数出“一个”“两个”？能数 → many；不能数 → much。⚠️ money 不可数：*much money*。
  3. **haven't got ≠ don't have**（意思相同，但 haven't got 是英式口语常用说法）：本课练习 A 正是把 *don't have* 改写为 *haven't got*。注意：*hasn't got* 用于 he/she/it；*haven't got* 用于 I/you/we/they。
  4. **店铺名称带 's 且前面要用 the**：*go to the grocer's* ✓ / *go to grocer* ✗ —— 口语里定冠词 **the** + 店名 **'s** 一起用：*the baker's, the chemist's*。注意 greengrocer's 拼写：green + grocer → **greengrocer**（两个 g 连写、不要拆开）。
</Callout>

## 8. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3–5 遍。重点练 **must** 干脆利落的节奏和 *the grocer's* / *the chemist's* 的连读（the 轻读 + 's 轻读 /z/）。
  - **店铺接龙**：从 grocer's 到 chemist's，六家店一家不落，各说一遍 *I must go to the ... to get some ...*。然后不看图，凭记忆再说一遍。
  - **造句迁移**：用今天学的核心结构造自己的句子——
    1. *I must go to the ... to get some ...* —— 替换店名和商品，造 6 句：*I must go to the supermarket to get some milk.*
    2. *I need a lot of ... I haven't got much / many.* —— *I need a lot of rice. I haven't got much.* / *I need a lot of apples. I haven't got many.*
    3. *Have you got any ...? — No, I haven't got much / many.* —— 用身边的东西练问答。
  - **much vs many 清单**：在纸上画一条竖线，左边写“MUCH +”（不可数），右边写“MANY +”（可数复数）。把 bread, butter, milk, cheese, meat, beef, medicine, money, tea, coffee 写左边；把 eggs, tomatoes, potatoes, biscuits, envelopes, magazines, bananas, apples 写右边。每天早上念一遍——这是英语里最基本的语感地基。
  - **实际应用**：下次你去超市或菜市场，心里默念：*What do I need? I must get some ... I haven't got much / many ...* ——把课堂搬进生活，比任何课后练习都管用。
  - **跨课连接**：本课是第 79 课 *Carol's shopping list* 的句型操练场。把两课合在一起：先读完第 79 课的对话，再来本课做书面练习 A 和 B——你会发现 must / need / have got / much / many 这五个词你已经能一口气用对了。
