## The Drills 句型操练

本课是句型操练课——没有长篇课文，而是用 **一组插图 + 一块黑板上的替换句型** 把上一课学的 *Do you like ...? / Do you want ...?* 练熟。黑板上写着两行“公式”：

### 基本句型 Patterns on the blackboard

| 句型 | 问 | 答 |
|---|---|---|
| **Do you like ...?** | Do you like **butter**? | Yes, I do. I like butter, **but I don't want any**. |
| **Do you want ...?** | Do you want **any butter**? | Yes, please. / No, thank you. |

## 句型笔记 Pattern notes

<Callout type="info" title="6 个值得停下来嚼一嚼的点">
  1. **Do you like + 名词?** (l.1, l.9) — 问对方“**一贯的喜好**”，不是问“此刻要不要”。助动词 **do** 放在主语 **you** 前面构成一般疑问句——因为 like 是**实义动词**，不能像 be 动词那样直接提前。答语用 **Yes, I do. / No, I don't.**（do/don't 代替 like，不重复动词）。
  2. **Do you want + 名词?** (l.3, l.5, l.7, l.11) — 问对方“**此刻的意愿**”——要不要来一个 / 来一点。与 like 不同：*Do you like coffee?* = 你喜欢咖啡吗（一般喜好）；*Do you want a cup?* = 你想要一杯吗（现在）。答语更常用 **Yes, please. / No, thank you.**，这是礼貌的接受 / 谢绝，比 *Yes, I do.* 更自然。
  3. **I don't want any. / I don't want one.** — 句末用 **any** 还是 **one**，看名词是**不可数**还是**可数单数**：butter、honey、jam、whisky、beer、wine 是不可数名词→ *I don't want **any**.*；egg、banana、orange、biscuit、apple 是可数名词→ *I don't want **one**.*（复数则说 *I don't want **any**.* 或 *I don't want **any** oranges.*）。
  4. **I like black coffee.** (l.8) — “清咖啡 / 黑咖啡”。black coffee = 不加奶的咖啡；white coffee = 加奶的咖啡。这是英美日常叫法。注意 *black coffee* 前不加冠词（coffee 在此是不可数名词）。
  5. **one** 的指代用法 (l.11) — *Do you want **one**?* 里的 one = a biscuit，**代替前面提过的可数名词单数**，避免重复。中文里只说“你要一块吗”，英文用 one 这个“代名词”。
  6. **any vs. some** — **否定句和疑问句**里用 **any**：*Do you want **any** sugar?*、*I don't want **any**.* **肯定句**里用 **some**：*I want **some** sugar.*。但注意：**礼貌提供**的问句（Would you like ...）里用 some：*Would you like **some** honey?*
</Callout>

## 3. 关键句型：一般现在时的疑问句和否定句（实义动词 like / want）

<Callout type="tip" title="一分钟回顾：like 和 want 不是 be 动词，要请 do 来帮忙">
  第 1 课学了 be 动词（is）的问句——直接把 is 提前：*This is your handbag. → **Is** this your handbag?*。但 **like** 和 **want** 是**实义动词**（有实际含义的动作动词），不能自己提前——需要请助动词 **do**。

  | 句式 | like / want（实义动词） | be（be 动词） |
  |---|---|---|
  | 肯定句 | I **like** coffee. | This **is** your handbag. |
  | 否定句 | I **don't like** milk. | This **is not** your handbag. |
  | 疑问句 | **Do** you like coffee? | **Is** this your handbag? |
  | 简略肯定回答 | Yes, I **do**. | Yes, it **is**. |
  | 简略否定回答 | No, I **don't**. | No, it **isn't**. |

  **规则一句话**：实义动词（like, want, eat, drink, know ...）变问句和否定句**必须借 do/does**；be 动词（am/is/are）**自己就能变**。

  ### ⚠️ 4 个本课最容易踩的雷区

  1. **别把 like 当 be 动词用**：*Do you like coffee?* ✓ / *Are you like coffee?* ✗。like 是实义动词，问句要请 do。
  2. **否定句用 don't，不是 isn't**：*I don't like milk.* ✓ / *I isn't like milk.* ✗。isn't 是给 be 动词用的。
  3. **简略回答用 do/don't，不重复动词**：*Yes, I do.* ✓ / *Yes, I like.* ✗（不完整，like 缺宾语）。
  4. **不可数名词做 want 宾语时前面加 any**：*Do you want **any** butter?* ✓ / *Do you want butter?* 语法也对，但加上 any 更自然。
</Callout>

## 4. 难点：any 还是 one？——可数与不可数名词

<Callout type="info" title="把“可数/不可数”对上“any/one”，别混了">
  这是本课**最核心的一个区分**——不管操练句型还是做书面练习，都绕不开：

  | 名词类型 | 否定回答 | 例句 |
  |---|---|---|
  | **不可数**（butter, honey, jam, whisky, beer, wine, milk, sugar） | not want **any** | I like honey, but I don't want **any**. |
  | **可数单数**（banana, orange, egg, biscuit, apple） | not want **one** | I like bananas, but I don't want **one**. |
  | **可数复数**（eggs, oranges, biscuits） | not want **any** | I like biscuits, but I don't want **any**. |

  **一句话记**：不可数名词量是“不可分割的整体”→用 **any**（“一点也不”）；可数单数是一个一个的个体→用 **one**（“一个也不要”）；可数复数也是一堆东西→用 **any**。

  最常见错误：*I like butter, but I don't want **one**.* ✗ —— butter 不能“一个”，只能是“一点”。
</Callout>

## 9. 词汇辨义：like vs. want · any vs. some · 形容词 fresh / pure / ripe / sweet

<Callout type="info" title="别把相近的词用混了">
  本课的生词很多是形容词，容易记串。下面把它们放进语境里区分：

  - **fresh**（新鲜的）vs. **ripe**（成熟的）：fresh eggs 刚下的鸡蛋；ripe bananas 熟透的香蕉。fresh 强调“没变质”；ripe 强调“熟透了可以吃”。

  - **sweet**（甜的）vs. 其它甜味词：sweet 是本课学的“甜的”，注意和 sweets（糖果复数）区分——*These oranges are sweet.*（这些橙子很甜）vs. *Do you want some sweets?*（你想要些糖果吗）。

## 11. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。重点练：
    - *Do you like ...?* 的句末**升调**（Yes/No 问句用升调）
    - *Do you want ...?* 的礼貌节奏
    - *but I don't want any/one.* 中 **but** 的转折停顿
  - **句型迁移——举一反百**：用今天学的两个句型，把你家厨房里的东西全问一遍：
    1. *Do you like **rice**?* — *Yes, I do. I like rice, but I don't want any.*
    2. *Do you like **bread**?* — *Yes, I do. I like bread, but I don't want any.*
    3. *Do you like **cheese**?* — *Yes, I do. I like cheese, but I don't want any.*
    4. *Do you like **tomatoes**?* — *Yes, I do. I like tomatoes, but I don't want one.*
    5. *Do you like **potatoes**?* — *Yes, I do. I like potatoes, but I don't want one.*
    **关键**：每造一句前，先判断名词是**可数还是不可数**——这决定了句末用 **any** 还是 **one**。
  - **角色扮演**：一人问 *Do you like ...?*，另一人按本课句型回答——先肯定（*Yes, I do. I like ...*），再转折（*but I don't want any/one.*）；然后换 *Do you want ...?*，对方用 *Yes, please. / No, thank you.* 礼貌回应。轮换 10 个食物名词，练到不假思索。
  - **do / does 对照表**：把今天学的“实义动词问句借 do”记牢——自己在纸上默写这个对照表：
    | 主语 | 肯定 | 否定 | 疑问 |
    |---|---|---|---|
    | I / You / We / They | like coffee | **don't** like coffee | **Do** you like coffee? |
    | He / She / It | like**s** coffee | **doesn't** like coffee | **Does** he like coffee? |
    **记住铁律**：第三人称单数的 -s 在肯定句里加在动词上（likes），在否定句和疑问句里被 does 吃掉（doesn't like / Does ... like?——动词恢复原形）。
  - **any vs. some 三步记**：①肯定句→some（*I want some sugar.*）；②否定句/一般疑问句→any（*I don't want any sugar. / Do you want any sugar?*）；③礼貌提供→some（*Would you like some sugar?*）。绕口三次，形成肌肉记忆。
  - **生词串记**：把 16 个生词分成四组背——**调味品组**（butter 黄油、honey 蜂蜜、jam 果酱）、**水果组**（banana 香蕉、orange 橙子、apple 苹果）、**饮品组**（wine 葡萄酒、beer 啤酒、Scotch whisky 苏格兰威士忌）、**形容词组**（fresh 新鲜的、pure 纯净的、ripe 成熟的、sweet 甜的、choice 上等的）——每组连成一个小场景说出来。
