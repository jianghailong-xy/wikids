### 想一想

<Callout type="info" title="观察：复数物品用 they 指代">
  10 幅图里，每幅的第一句话都是用 **There are some ...** 描述"某处有复数物品"，第二句用代词 **they** 指代这批物品并给出更精确的位置。注意看——第一句的名词都是复数（cigarettes / trousers / shoes / forks / tickets / plates / bottles / knives / glasses），所以第二句一律用 **they** 来指代，绝不出现 *it*。这个道理很简单：**单数用 it，复数用 they**，和中文的"它 / 它们"一回事，只是英语里用得更严格。
</Callout>

## 课文注释 Notes on the text

<Callout type="info" title="6 个值得停下来嚼一嚼的点">
  1. **trousers** — "长裤（复数）"。这是一个 **永远用复数形式** 的名词——英语里说"一条裤子"是 *a pair of trousers*，而不是 *a trouser*；说"裤子在床上"是 *The trousers are on the bed.*（be 动词用 are，不用 is）。同型词：*glasses*（眼镜）、*scissors*（剪刀）、*shorts*（短裤），都按复数处理、都要用 *a pair of* 来说"一副 / 一把 / 一条"。

  2. **There are some ...** (全文) — "有一些……"。在肯定句中，**some** 修饰复数可数名词，表示不确定的"几个 / 一些"。10 幅图全部以 *There are some + 复数名词 + 表示地点的介词短语* 开头——这是英语最基础的"存在句"复数形式。句式：[There are] + [some + 名词复数] + [地点]。⚠️ 和上一课 Lesson 27 里反复出现的 *There is a ...*（单数）对比着记：单数名词前用 **a/an**，复数名词前用 **some**。

  3. **They are / They're** (全文) — "它们（是）……"。**They're** 是 **They are** 的缩略形式，口语里极常用。课文中两种写法都出现了：Picture 3、4、5、8、9、10 用了缩略 *They're*，Picture 1、2、6、7 用了完整 *They are*——两者完全等价，但初学者建议先写全形，口语跟读时放心地用缩略。

  4. **near** (Picture 1, 2, 3, 4, 9, 10) — "靠近、在……附近"，介词。课文里大量出现 *near that box / near that shirt / near the bed / near those spoons / near those tins / near those bottles*。对比：**near**（在附近，不一定是紧挨着）、**by**（在旁边，比 near 更近）、**next to**（紧挨着）。本课统一用 near，强调的是"在……周围那片区域里"。

  5. **that / those** (全文) — "那个 / 那些"。**that** 修饰单数名词（*that box / that shirt / that handbag / that tin*），**those** 修饰复数名词（*those spoons / those tins / those bottles*）。在方位表达中，that 和 those 起到"指给你看"的作用——说的是"那一个／那些个"，不是随便哪个。

  6. **clean / empty** (Picture 6, 7) — "干净的 / 空的"。两句用了形容词作表语，描述了物品的状态：*They are clean.*（它们是干净的）= 盘子洗干净了；*They are empty.*（它们是空的）= 瓶子喝完了。观察：这里 be 动词后面不再跟地点，而是跟**形容词**——说明 *They are + 形容词* 和 *They are + 介词短语* 是 be 动词后面可以接的两种不同成分。
</Callout>

## 3. 关键句型：There are + 复数名词 · Where are they?

<Callout type="tip" title="一分钟回顾：There be 句型的复数版">
  上一课我们学会了 **There is + 单数名词**（某处有一个……），本课升级到复数版——**There are + some + 复数名词**（某处有一些……）。把两种句型放进同一张表，规律一目了然：

  | | 单数 Singular | 复数 Plural |
  |---|---|---|
  | **存在句** | There **is** a book on the desk. | There **are** some books on the desk. |
  | **提问** | Where **is** the book? | Where **are** the books? |
  | **回答** | **It**'s on the desk. | **They**'re on the desk. |
  | **否定存在** | There **isn't** a book. | There **aren't** any books. |
  | **疑问存在** | **Is there** a book? | **Are there** any books? |

  把这张表背下来，等于把 NCE1 第 25–28 课的四个句型"全家福"装进了口袋。

  ### ⚠️ 5 个本课最容易踩的雷区

  1. **There are 后面是复数名词，不能跟 a/an**：*There are **some** magazines.* ✓ / *There are **a** magazines.* ✗ —— a/an 只能跟单数名词。
  2. **复数用 they 指代，不用 it**：*Where are the glasses? — **They**'re on the television.* ✓ / *It's on the television.* ✗ —— glasses 是复数，必须用 they。
  3. **肯定句用 some，否定 / 疑问句用 any**：*There are **some** books.* ✓ / *There aren't **any** books.* ✓ / *Are there **any** books?* ✓ —— 这是本课 Written Exercise B 核心操练的规则。
  4. **回答 There be 问句时照搬 be 动词**：*Are there any books? — Yes, there **are**. / No, there **aren't**.* ✓（不能用 *Yes, they are.* —— 那是回答 *Where are they?* 的问法）。
  5. **trousers / glasses 永远复数，be 动词配 are**：*The trousers **are** on the bed.* ✓ / *The trousers **is** on the bed.* ✗ —— 这类"天然复数"名词，be 动词永远是 are。
</Callout>

## 9. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。重点练 **There are some ...** 的完整句节奏——把复数名词的尾音 -s/-es 读清楚（plates 的 /s/、bottles 的 /z/、knives 的 /vz/），不要把复数的 -s 吞掉。
  - **看图说话**：合上课本，看着 10 幅插图（或凭记忆）给每幅分别说出一句 *There are some ...* + 一句 *They are ...*，说到流畅为止。
  - **问答链条 (Question chain)**：找身边 5 组复数物品（比如房间里的书、桌上的笔、厨房的杯子），每组练一遍完整链条——**Are there any ...? → No, there aren't any ... → There are some ... → Where are they? → They're ...**。用这个链条和朋友一问一答，最练口语反应。
  - **造句迁移**：用本课的 5 个句型造自己的句子——
    1. *There are some + 复数名词 + 地点* —— *There are some apples in the bowl.*
    2. *They are + 介词短语（方位）* —— *They are on the top shelf.*
    3. *They are + 形容词（状态）* —— *They are fresh.*
    4. *Are there any ...? — No, there aren't any ...* —— *Are there any eggs in the fridge? — No, there aren't any eggs.*
    5. *他们／它们在哪里？— 他们／它们在……* —— *Where are they? — They're in the drawer.*
  - **单复数对照**：自己画一张表，左栏用 Lesson 27 的 *There is a ... Where is it? It's ...*、右栏用 Lesson 28 的 *There are some ... Where are they? They're ...*——把本课每幅图的内容拆进两张表里，让"单数 → 复数"的转换变成一种直觉。
  - **听写**：听录音，把 10 幅图的全部第二句话默写下来，特别注意每句的代词 they 和缩略形式 They're。
</Callout>
