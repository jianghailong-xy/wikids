  厨房里，彭妮（Penny）在烧水沏茶。她招呼萨姆（Sam）过来帮忙——**"Sam，你能沏茶吗？"** 萨姆一口答应。可接下来的一幕让人忍俊不禁：水壶里有水，没问题；但茶叶在哪儿？在茶壶后面——找到了；茶杯又在哪儿？在碗橱里——也找到了。眼看东西都齐了，彭妮却忽然急得催了起来：**"快点，Sam！水开了！"** 一个厨房、一壶水、一对小夫妻——本课用短短十几句对话，第一次把同学引入情态动词 **can** 的日常用法。

  本课的"听前问题"是：**Can Sam make the tea? 萨姆会沏茶吗？** 带着这个问题听录音、读课文，重点留意 **can** 表"能够 / 会"的肯定、否定与疑问三种句式，以及 **There + be** 的方位表达和 **behind / in front of** 等方位介词。全课的语法核心就是一句话——**can 后面永远接动词原形，所有人称都不变形**。
</Callout>

## The Text 课文

PENNY: **Can you make the tea**, Sam?

SAM: Yes, **of course** I can, Penny.

SAM: Is there any water in this **kettle**?

PENNY: Yes, there is.

SAM: **Where's the tea?**

PENNY: It's over there, **behind** the **teapot**.

PENNY: Can you see it?

SAM: I can see the teapot, but I **can't see** the tea.

PENNY: **There it is**! It's **in front of** you!

SAM: Ah yes, I can see it **now**.

SAM: **Where are the cups?**

PENNY: There are some **in the cupboard**.

PENNY: **Can you find them?**

SAM: Yes. **Here they are**.

PENNY: **Hurry up**, Sam! The kettle's **boiling**!

## 课文注释 Notes on the text

<Callout type="info" title="7 个值得停下来嚼一嚼的点">
  1. **Can you make the tea?** (l.1) — "你能沏茶吗？" **can** 是情态动词（modal verb），表示"能够、会"。**Can you ...?** 是询问某人能否做某事最常用的句型，既表能力也表请求。⚠️ 关键规则：**can 后面永远接动词原形**（不接 to do、不接 -ing、不加 s），且所有人称（I / you / he / she / it / we / they）一律用 can——没有 cans 这种形式。

  2. **of course** (l.2) — "当然"。表示欣然同意、毫无疑问，相当于 certainly。口语中既可用于完整句 *Yes, of course I can.* 也可单独成句：*Can you help me? — Of course.* 同型：*Of course you can come in.*（你当然可以进来）。

  3. **Is there any water in this kettle?** (l.3) — "这个水壶里有水吗？" 这是第 25–28 课学过的 **There + be** 存现句疑问式。注意 water 是不可数名词，所以用 **Is there any water**（不用 Are there）。相关结构：*Is there any milk? / Is there any bread?* —— any 用于疑问和否定句中。

  4. **kettle vs teapot** (ll.3, 6) — **kettle** /ˈketl/ 是烧水用的壶（水壶），通常在炉子上烧开水；**teapot** /ˈtiːpɒt/ 是泡茶用的壶（茶壶），用来放茶叶、倒热水进去泡。课文里 Sam 先检查烧水壶里有没有水，然后才去茶壶后面找茶叶——两个壶分工不同。

  5. **behind / in front of** (ll.6, 9) — 一对反义方位介词。**behind** = 在……后面；**in front of** = 在……前面（某一物体范围之外的"前面"）。⚠️ 区分 **in front of**（范围外的前面）和 **in the front of**（范围内的前部）：*The teapot is in front of the kettle.*（茶壶在水壶前面——壶外）vs *He sat in the front of the car.*（他坐在汽车的前座——车内）。

  6. **I can see ... but I can't see ...** (l.8) — "我能看见……但我看不见……"。**can't** /kɑːnt/ 是 **cannot** 的缩写形式，意为"不能"。注意英式发音中 can't 的元音与 can 不同（can /kæn/ → can't /kɑːnt/），口语中的区分主要靠元音长度。**cannot** 写作一个词（不是 can not 分写），仅在极端强调时偶尔分写 *can not*。

  7. **Hurry up!** (l.15) — "快点！赶紧！" 这是口语中催别人加快速度最常用的 **祈使句**（imperative）。hurry 是动词，up 是副词小品词——祈使句直接用动词原形开头。同型：*Hurry!*（快！——略简略）/ *Come on!*（快来！/ 加油！——更有鼓励口气）/ *Be quick!*（快点儿！——程度较轻）。
</Callout>

## 3. 关键句型：情态动词 can / can't — 表示能力

<Callout type="tip" title="一分钟回顾：情态动词 can —— 英语里最万能的『能』字">
  本课的核心语法是新概念第一册第一次系统引入的 **情态动词 can**——它用来表示"能够、会"（能力），或"可以"（允许），或"能不能帮我……"（请求）。

  can 的使用口诀：**"can 后原形永不变，三单五人都一体"**——不管主语是 I、you、he、she、it、we、they，can 永远不变形，后面永远跟动词原形。

  | 句式 | 结构 | 课文例 |
  |---|---|---|
  | **肯定句** | 主语 + **can** + 动词原形 | *I can see the teapot.* |
  | **否定句** | 主语 + **can't** (cannot) + 动词原形 | *I can't see the tea.* |
  | **疑问句** | **Can** + 主语 + 动词原形 ? | *Can you make the tea?* |
  | **简略答** | Yes, 主语 can. / No, 主语 can't. | *Yes, of course I can.* |

  ### ⚠️ 5 个本课最容易踩的雷区

  1. **can 后面是动词原形，不是 to do**：*I can swim.* ✓ / *I can to swim.* ✗ / *I can swimming.* ✗ —— can 是情态动词，永远和动词原形搭配。
  2. **can 三单不加 s**：*She can type.* ✓ / *She cans type.* ✗ —— can 没有单三变化，can 后面更没有 can be typing 这种进行式。
  3. **否定用 can't（英式发音 /kɑːnt/），不是 don't can 也不是 not can**：*I can't see it.* ✓ / *I don't can see it.* ✗ / *I not can see it.* ✗
  4. **疑问句把 can 提前，不用 do / does**：*Can you swim?* ✓ / *Do you can swim?* ✗ —— 情态动词自己就能提问，不需要助动词 do/does/did。
  5. **can = be able to（能力）**：在现在时中，can 和 am/is/are able to 可以互换。*I can make the tea. = I am able to make the tea.*（我会泡茶。）
</Callout>

## 8. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。重点练 **can you ...?** 的句末升调（表示礼貌请求），以及 *I can see ... but I can't see ...* 中 can 与 can't 的元音对比——*can* /kæn/ 短而轻，*can't* /kɑːnt/ 长而重。
  - **复述 (retell)**：合上课文，用 1 分钟把 Sam 的「找茶叶→找杯子→被催」三部曲讲一遍。三步走：① Penny 请 Sam 泡茶 → Sam 答应，先检查水壶有水；② Sam 找茶叶（被茶壶挡住）→ Penny 指给他，茶叶就在面前；③ Sam 找杯子（在碗橱里）→ 找到了 → Penny 催他快点，水开了。
  - **造句迁移**：用今天学的 5 个结构造你自己的句子——
    1. **Can you ...?**（请求帮忙）—— *Can you open the window, please?*
    2. **I can ... but I can't ...**（肯否对比）—— *I can read English, but I can't speak it very well.*
    3. **There be + 方位**（存现句）—— *There are some cups in the cupboard.*
    4. **behind / in front of**（方位）—— *The garden is behind the house. / The car is in front of the building.*
    5. **Hurry up!**（祈使句催人）—— *Hurry up! The bus is coming!*
  - **厨房场景对话**：造一段 6 句以上的厨房对话，至少用到 can you ... 2 次 + There be 2 次 + behind / in front of 各 1 次 + Hurry up!。例：*Can you pass me the salt? It's behind the oil bottle. — Yes. Where are the plates? — There are some in the cupboard. — Can you set the table? — Of course. — Hurry up! The soup is ready!*
  - **语法迁移（承上启下）**：本课是 NCE1 第一次引入情态动词 **can**。下一课 Lesson 44（双数操练课）会围绕 *Are there any ...? / Is there any ...?* 做进一步的 There be 句型替换操练。而第 45 课 *The boss's letter* 将继续深化 can 的用法——请求（*Can you come here a minute, please?*）+ 能力（*I can't type this letter!*）。把本课 can 的肯定、否定、疑问三种句式练熟，后面连续几课都会用到。
