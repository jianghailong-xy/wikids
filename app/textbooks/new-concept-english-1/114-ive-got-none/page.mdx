## The Pattern Drill 句型操练

先看**句型对照表**。本课练两个核心"接头"：

- **否定的四种说法**：*I **haven't got any**.* → *I've got **no** ...* → *I've got **none**.* → *I **haven't any either**.* / ***Neither** have I.*
- **肯定的两种说法**：*I've got **some**.* → ***So** have I.*

下面四组插图操练——前两组练否定，后两组练肯定，把上面的句式放进真实问答里用一遍：

### 否定回答：我没有……

#### Group 1 — chocolate 巧克力

> **Have you got any chocolate?** 你有巧克力吗？

*I **haven't got any**.* 我没有（巧克力）。

*I've got **no chocolate**.* 我没有巧克力。

*I've got **none**.* 我一点也没有。

*I **haven't any either**.* 我也没有。

***Neither** have I.* 我也没有。

#### Group 2 — envelopes 信封

> **Have you got any envelopes?** 你有信封吗？

*I **haven't got any**.* 我没有（信封）。

*I've got **no envelopes**.* 我没有信封。

*I've got **none**.* 我一个也没有。

*I **haven't any either**.* 我也没有。

***Neither** have I.* 我也没有。

### 肯定回答：我有……

#### Group 3 — cake 蛋糕

> **Have you got any cake?** 你有蛋糕吗？

*I've got **some**.* 我有一些。

***So** have I.* 我也有。

#### Group 4 — biscuits 饼干

> **Have you got any biscuits?** 你有饼干吗？

*I've got **some**.* 我有一些。

***So** have I.* 我也有。

## 课文注释 Notes on the text

<Callout type="info" title="6 个值得停下来嚼一嚼的点">
  1. **none — 一个也没有 / 一点也没有**：none 是一个**代词**，代替 *not any + 名词* 或 *no + 名词*，把话说得**最干脆利落**。*I've got **none**.* = *I haven't got any.* = *I've got no chocolate.* 三种说法意思一样，但 **none 最简短**，适合快速回答。⚠️ none 本身可以指代可数或不可数名词，因此 *I've got none.* 既可以表示"一个也没有"（可数），也可以表示"一点也没有"（不可数）。

  2. **not ... any → no 的转换**：这是本课 Exercise A 的核心技能。*There isn't **any** milk.* → *There is **no** milk.* 规则很简单：① 删掉 not（动词变肯定式）；② 把 any 换成 no（放在名词前）。注意动词的人称和数（isn't → is / aren't → are / didn't → 过去式肯定动词）。同型转换：*I **didn't** see **any** cars.* → *I saw **no** cars.*

  3. **Neither ... I — 否定句的倒装呼应**：当上一句是否定结构，你想说"我也一样（不）"时，用 **Neither + 助动词 / be 动词 + I**。助动词要跟上一句的助动词 / be 动词**保持一致**：*I'm **not** tired.* → ***Neither am** I.* / *I **didn't** meet him.* → ***Neither did** I.* / *I **can't** swim.* → ***Neither can** I.* ⚠️ neither 本身已经含有否定意义，后面用**肯定式动词**，不要加 not（*Neither am not I* ✗）。

  4. **So ... I — 肯定句的倒装呼应**：当上一句是肯定结构，你想说"我也一样"时，用 **So + 助动词 / be 动词 + I**。规则和 Neither 完全对称——助动词跟着上一句走：*I **am** tired.* → ***So am** I.* / *I **met** him.* → ***So did** I.* / *I **can** swim.* → ***So can** I.* ⚠️ So 用于肯定呼应，Neither 用于否定呼应——**选哪个看上一句是肯定还是否定**，不要混用。

  5. **haven't any 和 haven't got any — 两种"没有"**：本课同时出现了两种否定结构：① *I **haven't got** any.*（have got 的否定式，口语中最常见）② *I **haven't** any either.*（have 直接否定，省略 got，也是标准英式用法）。两种都可以，**前者更口语化**。在 Some 和 Any 这个语法大主题上，NCE1 用这两套说法帮你灵活切换。

  6. **either vs. neither 的区分**：*I haven't any **either**.* 里的 **either** 是副词，放在否定句**末尾**，表示"也（不）"。而 ***Neither** have I.* 里的 **neither** 放在**句首**，引导倒装句，也表示"我也不……"。意思一样但位置和搭配不同：either 跟着正常否定语序走（not ... either）；neither 走倒装句首。⚠️ 初学者最容易把 *Neither have I.* 写成 *Neither I have.*（不倒装 ✗）。
</Callout>

## 11. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3–5 遍。本课核心节奏在于 **none 的干脆收尾**（一个音节，嘴巴闭紧 /n/）和 **Neither / So 倒装句的升降调**——*Neither have `I.`*（I 读降调表示确认），*So have `I.`*（同样 I 读降调）。注意 either /ˈaɪðə/ 和 neither /ˈnaɪðə/ 的首音不同——either 没有 /n/，neither 有 /n/。
  - **复述 (retell)**：合上教材，凭记忆说出本课否定回答的四种说法（haven't got any / 've got no / 've got none / haven't any either + Neither have I）和肯定回答的两种说法（'ve got some / So have I）。
  - **造句迁移**：用今天学的 5 个核心结构各造两个你自己的句子——
    1. ***haven't got any*** 否定：*I haven't got any time today. / She hasn't got any brothers.*
    2. ***no + 名词*** 改写：*There is no sugar left. / I have no idea.*
    3. ***none*** 干脆回答：*How much coffee is left? None. / Any questions? None.*
    4. ***Neither ... I*** 否定呼应：*I don't like cold weather. — Neither do I. / I've never been to Paris. — Neither have I.*
    5. ***So ... I*** 肯定呼应：*I love this song. — So do I. / I went to bed early. — So did I.*
  - **防坑自查**：下面三个是本课最高频的错误：
    - ❌ *I haven't got **no** money.* → ✓ *I **haven't got any** money.* 或 *I've got **no** money.*（no 不配 not）
    - ❌ *I'm not hungry. — **So** am I.* → ✓ *I'm not hungry. — **Neither** am I.*（否定用 Neither，肯定用 So）
    - ❌ *I can't swim. — Neither **I can**.* → ✓ *I can't swim. — Neither **can I**.*（Neither 后必须倒装）
  - **延伸应用**：下次朋友说 *I don't have any plans for the weekend.*，别只会说 Me too（语法上有争议），试试干净利落的 ***Neither do I.***——这是本课的核心绝技。同理，朋友说 *I've been to London.*，用 ***So have I.*** 比 Me too 更正式、更准确。
</Callout>
