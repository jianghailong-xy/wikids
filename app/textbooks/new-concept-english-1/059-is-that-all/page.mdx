  走进一家文具店——一位女士想买信封、信纸、胶水，还有一大盒粉笔。可是售货员翻来找去，偏偏只有小盒的粉笔……女士一件件说要什么，售货员一件件递过来，对话快得像流水线上的扫码结账。最后售货员问了一句 **"Is that all?"**（就这些吗？），女士说"就这些"——然后又补了一句让人忍俊不禁的话。这篇对话看似日常购物，实则是一堂密集的 **some / any / ones 实操课**：肯定句用 *some*，否定和疑问用 *any*，复数名词不想重复就换 *ones*。

  *Listen to the tape then answer this question:* **Does the lady buy any chalk?** **听录音，然后回答问题：这位女士买粉笔了吗？** 带着这个问题听录音、读课文，重点留意对话中每个 some 和 any 出现的位置——肯定句？否定句？还是疑问句？找出规律，*some* 和 *any* 的区别你就拿下了。
</Callout>

## The Text 课文

**LADY:** I want **some envelopes**, please.

**SHOP ASSISTANT:** Do you want the large size or the small size?

**LADY:** The large size, please.

**LADY:** Do you have **any writing paper**?

**SHOP ASSISTANT:** Yes, we do.

**SHOP ASSISTANT:** I don't have any small pads. I only have large **ones**. Do you want **a pad**?

**LADY:** Yes, please.

**LADY:** And I want **some glue**.

**SHOP ASSISTANT:** A bottle of glue.

**LADY:** And I want **a large box of chalk**, too.

**SHOP ASSISTANT:** I only have small boxes. Do you want **one**?

**LADY:** No, thank you.

**SHOP ASSISTANT:** **Is that all?**

**LADY:** That's all, thank you.

**SHOP ASSISTANT:** What **else** do you want?

**LADY:** I want **my change**.

## 课文注释 Notes on the text

<Callout type="info" title="5 个值得停下来嚼一嚼的点">
  1. **Do you want the large size or the small size?** — 这是一个**选择疑问句**。选择疑问句由 **or** 连接两个选项，放在一般疑问句之后。回答时直接选择其中一个选项即可（如 *The large size, please.*），**不能用 Yes / No**。同型：*Is she a teacher or a doctor? — A teacher.* / *Do you like tea or coffee? — Coffee, please.*
  2. **I only have large ones.** — 句中 **ones** 代指前面提到的 pads（信纸簿），避免重复。**one** 用来代替单数可数名词，**ones** 代替复数可数名词。课文还有两处：*Do you want **one**?*（指 a box of chalk）；对比 *I don't have any small pads. I only have large **ones**.*（ones = pads）。
  3. **What else do you want?** — 你还想要什么？**else** 用于疑问词（what, who, where 等）之后，表示"另外的、其他的"。同型：*Who else is coming?*（还有谁来？）、*Where else did you go?*（你还去了哪里？）、*Is there anything else?*（还有别的吗？）。
  4. **some 和 any 的用法** — 本课最核心的语法。**some** 用于**肯定句**（*I want **some** envelopes.* / *I want **some** glue.*）；**any** 用于**否定句和疑问句**（*I don't have **any** small pads.* / *Do you have **any** writing paper?*）。这一对"肯定搭档"贯穿全对话，每读一句问自己：这是肯定还是否定/疑问？some 还是 any？
  5. **不可数名词** — 本课中的 paper（纸）、glue（胶水）、chalk（粉笔）均为**不可数名词**，不能直接加 a 或加 -s。要表示数量，需借助**量词**：*a piece of writing paper*（一张信纸）、*a bottle of glue*（一瓶胶水）、*a box of chalk*（一盒粉笔）。课文对话中售货员就是把不可数名词"量化"后递给顾客：*A bottle of glue.*
</Callout>

## 3. 关键句型：some 和 any 的用法

<Callout type="tip" title="一分钟回顾：肯定句用 some，否定/疑问用 any">
  本课全篇对话就是 some 和 any 的活教材——每读一句问自己：这是肯定句？否定句？还是疑问句？

  | 句型 | 用哪个 | 课文例句 |
  |---|---|---|
  | **肯定句** | **some** | *I want **some** envelopes.* |
  | **肯定句** | **some** | *I want **some** glue.* |
  | **否定句** | **any** | *I don't have **any** small pads.* |
  | **疑问句** | **any** | *Do you have **any** writing paper?* |

  ### ⚠️ 3 个本课最容易踩的雷区

  1. **肯定句不要错用 any**：*I want **some** envelopes.* ✓ / *I want any envelopes.* ✗ —— some 在肯定句中是"一些"，any 在肯定句中是"任何"，意思变了。
  2. **否定句不要错用 some**：*I don't have **any** small pads.* ✓ / *I don't have some small pads.* ✗ —— 否定句中用 any，not ... any = 一点也没有。
  3. **疑问句通常用 any**：*Do you have **any** writing paper?* ✓ / *Do you have some writing paper?* —— 用 any 更自然；用 some 也可以，但暗含"期待肯定回答"的语气（如请客时问 *Would you like some tea?*）。
</Callout>

## 4. 句型操练：用 some 或 any 写句子

### Exercise A — 用 some 或 any 填空

<Callout type="info" title="题目：Complete these sentences using some or any.">
  模仿课文 *I don't have **any** small pads. I only have large **ones**.* 的模式，用 some 或 any 填空：

  1. I don't have \_\_\_ tomatoes, but I have \_\_\_ potatoes.
  2. I don't have \_\_\_ mince, but I have \_\_\_ steak.
  3. I don't have \_\_\_ glue, but I have \_\_\_ ink.
  4. I don't have \_\_\_ envelopes, but I have \_\_\_ writing paper.

  （答案：1. any / some　2. any / some　3. any / some　4. any / some）
</Callout>

### Exercise B — 模仿例句写出句子

<Callout type="info" title="题目：Write sentences following the pattern.">
  先看例句：

  > **Penny and I / honey / jam**
  > → **Penny and I don't have any honey, but we have some jam.**

  用下列主语和提示词，写出**否定句（any）+ 肯定句（some）**的配对句。注意代词的切换：*Penny and I* → but **we**；*Penny and Sam* → but **they**；*Sam and I* → but **we**。

  1. Penny and Sam / wine / beer
  2. Sam and I / bread / biscuits
  3. Penny and Sam / grapes / bananas
  4. I / mince / steak
  5. The children / butter / eggs
  6. I / lettuces / cabbages
  7. Penny and I / beans / peas
</Callout>

<Callout type="tip" title="参考答案（自己写完再对照）">
  1. **Penny and Sam don't have any wine, but they have some beer.**
  2. **Sam and I don't have any bread, but we have some biscuits.**
  3. **Penny and Sam don't have any grapes, but they have some bananas.**
  4. **I don't have any mince, but I have some steak.**
  5. **The children don't have any butter, but they have some eggs.**
  6. **I don't have any lettuces, but I have some cabbages.**
  7. **Penny and I don't have any beans, but we have some peas.**

  注意：**wine, bread, mince, butter** 均为不可数名词，不加 -s；**beer** 在此也按不可数处理；**biscuits, grapes, bananas, eggs, lettuces, cabbages, beans, peas** 是可数名词复数。
</Callout>

## 8. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。本课是对话，重点练**一问一答的语调起伏**——售货员的询问（上扬↗）和顾客的答复（下降↘）要有区分。
  - **角色扮演**：找一个人搭档，把文具店的对话从头到尾演一遍。一方当顾客（Lady），一方当售货员（Shop Assistant）。练到能**脱稿对答**为止——这正好是一次真实的购物场景模拟。
  - **造句迁移**：用今天学的 5 个结构造你自己的句子——
    1. *some + 复数名词*（肯定句）—— *I want some stamps, please.*（我要几张邮票。）
    2. *Do you have any + 名词?*（疑问句）—— *Do you have any orange juice?*（你有橙汁吗？）
    3. *I don't have any ... I only have ...*（否定 → 肯定对比）—— *I don't have any books. I only have notebooks.*
    4. *a bottle / a box / a piece of + 不可数名词* —— *Can I have a piece of paper?*（能给我一张纸吗？）
    5. *Is that all? / That's all.* —— 购物结账时最实用的两个句子，练到脱口而出。
