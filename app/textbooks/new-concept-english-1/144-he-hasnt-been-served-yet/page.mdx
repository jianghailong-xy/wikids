  - **还没被…… / 很快会被……**（现在完成时否定 & 将来时被动）：*He hasn't been caught yet. He will be caught soon.* 还没被抓到。/ 很快会被抓到。

## The Pattern Drill 句型操练

本课是句型操练课。下面四组插图操练，每组都有一问一答——问句是 **Hasn't anyone ... yet?（还没人……吗？）**，答句分两种：一种说"已经做好了"（present perfect passive），一种说"还没做好，但很快会做"（present perfect negative + future passive）。

### 第一组：已经修好了 · 已经改好了

**画面 1 — 修车**

— Hasn't anyone repaired this car yet?（还没人把这辆车修好吗？）
— **It has already been repaired!**（已经修好了！）

**画面 2 — 改作业本**

— Hasn't anyone corrected these exercise books yet?（还没人把这些作业本改好吗？）
— **They have already been corrected!**（已经改好了！）

<Callout type="tip" title="一分钟对比">
  - **has been repaired** = 现在完成时的被动：*has been + 过去分词*。主语是单数 it，用 **has**。
  - **have been corrected** = 主语是复数 they（exercise books），用 **have**。
  - **already** 放在 has/have 和 been 之间：*has **already** been repaired*。
  - 这两组说的是"**已经做好了**"——不用再等，事情已完成。
</Callout>

### 第二组：还没被抓到 · 很快会被抓到

**画面 3 — 抓小偷（单数）**

— Hasn't anyone caught the thief yet?（还没人抓住那个小偷吗？）
— **He hasn't been caught yet.**（他还没被抓到。）
— **He will be caught soon!**（他很快会被抓到的！）

**画面 4 — 抓小偷（复数）**

— Hasn't anyone caught the thieves yet?（还没人抓住那些小偷吗？）
— **They haven't been caught yet.**（他们还没被抓到。）
— **They will be caught soon!**（他们很快会被抓到的！）

<Callout type="tip" title="一分钟对比">
  - **hasn't been caught** = 现在完成时被动否定：*has not been + 过去分词*。主语是单数 he，用 **hasn't**。注意 **yet** 放句尾。
  - **haven't been caught** = 主语是复数 they，用 **haven't**。
  - **will be caught** = 将来时被动：*will be + 过去分词*。soon = 很快，马上。
  - 这两组说的是"**还没……，但会……**"——先否定现状，再承诺未来。
</Callout>

### 第三组：还没人侍候他

**画面 5 — 餐厅侍者**

— Hasn't anyone served him yet?（还没人来侍候他吗？）
— **He hasn't been served yet.**（还没有人来侍候他。）
— **He will be served soon.**（很快会有人来侍候他的。）

<Callout type="tip" title="本课标题就来自这一组">
  课文标题 *He hasn't been served yet. / He will be served soon.* 就是这一组的答句。**serve** 在餐厅语境里是"侍候、上菜招待"，被动式 *He hasn't been served* = 他还没被招待 / 还没人来给他上菜。将来时 *He will be served soon* = 很快就有人招待他。
</Callout>

## 课文注释 Notes on the text

<Callout type="info" title="6 个值得停下来嚼一嚼的点">
  1. **It has already been repaired.** — 这是 **现在完成时的被动语态**。构成公式：**has / have been + 过去分词**。*has* 用于单数主语（it / he / she），*have* 用于复数主语（they / the books）。already 插入在 has/have 和 been 之间，强调"已经"。

  2. **He hasn't been caught yet.** — 现在完成时被动的否定式，**has not been + 过去分词**。注意 **yet** 放在句末，表示"还没……"。同类：*They haven't been served yet.*（他们还没被招待。）*The room hasn't been cleaned yet.*（房间还没被打扫。）

  3. **He will be caught soon.** — 这是 **将来时的被动语态**。构成公式：**will be + 过去分词**。will 没有人称变化，所有主语都用 **will be**。soon = 很快、不久。同类：*The window will be opened tomorrow.*（窗户明天会被打开。）*The work will be finished next week.*（工作下周会被完成。）

  4. **Hasn't anyone ... yet?** — 这是本课操练的统一问句模板。**Hasn't anyone** = Has not anyone（否定疑问句），语气里带一点催促和不解——"还没人（做某事）吗？"。也可以说 Has anyone ... yet?（肯定疑问句）含义基本一样，但否定疑问句多了一层"按说早该做完了"的预期。同类：*Hasn't anyone told you?*（还没人告诉你吗？）*Hasn't anyone called the police?*（还没人报警吗？）

  5. **catch — caught — caught** — catch 是一个不规则动词，过去式和过去分词都是 **caught**。本文出现了 4 次：*Hasn't anyone **caught** the thief yet?*（现在完成时的原问句，caught 是过去分词）、*He hasn't been **caught** yet.*（被动式，caught 同样是过去分词）。同类：teach → taught / buy → bought / bring → brought。

  6. **主动 ↔ 被动的两条"语义路线"** — 本课操练反复对比同一件事的两种说法：
     - **Active 主动**：*Someone has repaired the car.*（有人修好了车。）——关注的是"谁做的"。
     - **Passive 被动**：*The car has been repaired.*（车被修好了。）——关注的是"车现在的状态"。
     
     口语里选主动还是被动，取决于你想强调"做事的人"还是"事情的结果"。本课的所有操练都是在被动这条"结果路线"上跑——不说谁做的，只说做没做完、什么时候会被做完。
</Callout>

## 3. 关键句型：被动语态 The passive voice

<Callout type="tip" title="一分钟回顾：被动语态就是把焦点从「谁做的」移到「事情的结果」">
  本课不是从头学被动——而是把被动语态放进两个你已经非常熟悉的时态里。先看两张总表：

  ### 现在完成时的被动：has / have been + 过去分词

  | 肯定句 | 否定句 | 疑问句 |
  |---|---|---|
  | It **has been repaired**. | It **has not been repaired**. | **Has** it **been repaired**? |
  | They **have been corrected**. | They **have not been corrected**. | **Have** they **been corrected**? |

  ### 将来时的被动：will be + 过去分词

  | 肯定句 | 否定句 | 疑问句 |
  |---|---|---|
  | He **will be caught** soon. | He **will not be caught**. | **Will** he **be caught**? |
  | They **will be served** soon. | They **will not be served**. | **Will** they **be served**? |

  ### ⚠️ 3 个本课最容易踩的雷区

  1. **过去分词不要写错**：被动语态的关键零件就是**过去分词**——catch → caught（不是 catched），sweep → swept（不是 sweeped），shut → shut（不是 shutted）。一张不规则动词表要在脑子里时刻待命。

  2. **has 还是 have？看主语是单还是复**：*The car **has** been repaired.* ✓ / *The car **have** been repaired.* ✗。主语是单数 it / he / she / the car 用 has，主语是复数 they / the books / the thieves 用 have。将来时的 will 没有这个问题——所有主语都用 **will be**。

  3. **already 和 yet 的位置**：already（已经）放在 has/have 后面、been 前面：*has **already** been done*。yet（还没）放在句末：*hasn't been done **yet***。两个副词都把"时间感"镶进被动句里，是口语最常用的两个"调味词"。
</Callout>

## 9. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 各跟读 3-5 遍。本课句型节奏分明——问句 *Hasn't anyone ... yet?* 带一点催促的语气上扬，答句的 *already been repaired* 则踏实落定，*will be caught soon* 略微上扬表示承诺。把这种"问—答"升降调练熟。

  - **句型替换操练**：拿 10 个常用动词（open, close, clean, wash, repair, empty, air, sharpen, water, dust），逐一套进两种被动句式：
    1. *It has already been **opened**.*（已经做了）
    2. *It hasn't been **opened** yet. It will be **opened** tomorrow.*（还没做，会做）

    每个动词两句话，10 × 2 = 20 句。这是本课的核心输出训练——练到不用想就能脱口说出正确的过去分词。

  - **场景造句**：用今天学的 5 个被动句式造你自己的真实句子——
    1. **has already been ...**（已经……了）——*The report has already been sent.* / *Dinner has already been cooked.*
    2. **hasn't been ... yet**（还没被……）——*My email hasn't been answered yet.* / *The floor hasn't been swept yet.*
    3. **will be ... soon**（很快会被……）——*You will be called soon.* / *The package will be delivered soon.*
    4. **Hasn't anyone ... yet?**（还没人……吗？）——*Hasn't anyone fed the cat yet?* / *Hasn't anyone told you the news yet?*
    5. **have already been ...**（复数主语，已经……了）——*The dishes have already been washed.* / *The letters have already been posted.*

  - **主动 ↔ 被动转换练习**：把下面主动句改成被动句，再改回来——
    - Active: *Someone has fixed the car.* → Passive: *The car has been fixed.*
    - Active: *They will open the shop tomorrow.* → Passive: *The shop will be opened tomorrow.*
    - Active: *No one has cleaned the room.* → Passive: *The room hasn't been cleaned.*
    - Active: *The police will catch the thief.* → Passive: *The thief will be caught.*

  - **不规则动词表抽查**：本课涉及的不规则动词——catch → caught, sweep → swept, shut → shut, buy → bought。每次练被动句之前，先过一遍这些过去分词的拼写，确保一个都不写错。建议把 catch-caught、sweep-swept、shut-shut 写在便利贴上贴在显眼处，练到条件反射。

  - **日常生活"被动观察"**：从明天起床开始，每遇到一件"被做好的事"，用英语被动句描述一次——*The bed has been made. / The coffee has been made. / The newspaper has been delivered. / The floor has been swept.* 一天攒 10 句，被动语态从此不再是"语法知识"，而是你每天张嘴就能用的句子。
</Callout>
