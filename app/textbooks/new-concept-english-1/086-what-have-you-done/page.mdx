  整个对话里藏着好几个现在完成时：**I've already seen it.**（我已经看过了。）**I've never been there.**（我从没去过那儿。）**Have you ever been there?**（你去过那儿吗？）——你看，说「已经做过某事」「从没做过某事」「曾经做过某事吗」，用的都是 **have / has + 过去分词**，这就是**现在完成时**。

## The Pattern Drill 句型操练

本课的模板只有一个——把一句祈使指令变成两句话：

> **I've already + 过去分词 …**（现在完成时：已经做过了）
> **I + 过去式 … + 时间状语**（一般过去时：什么时候做的）

下面按插图顺序列出本课 **13 组替换操练**。看插图、听录音，用上面的两句话轮换练习。留意：**过去分词的 -ed 怎么念**——aired /d/、cleaned /d/、opened /d/、sharpened /d/、boiled /d/、emptied /d/、asked /t/、washed /t/、walked /t/、dusted /ɪd/、painted /ɪd/ —— 三条发音规律藏在里面。

## 课文注释 Notes on the text

<Callout type="info" title="6 个值得停下来嚼一嚼的点">
  1. **I've already aired the room.** — 「我已经给房间通过风了。」**I've = I have**，后面接 **already + 过去分词 (aired)**，这是标准的现在完成时肯定句骨架：**主语 + have/has + already + 过去分词**。already 表示「已经」，让全句带上「事儿办完了」的语气。air 作动词意为「使通风」，它的过去式和过去分词都是 aired（直接加 -ed，读 /d/）。

  2. **I aired the room this morning.** — 「我今早给房间通的通风。」这句话**不再用现在完成时**，而是切换到**一般过去时**。为什么呢？因为句子里有了一个**具体的过去时间**：**this morning**（今早）。英语的铁律是：**有具体过去时间（this morning / yesterday / last night / an hour ago …），就必须用一般过去时，不能用现在完成时。** aired 在这里是一般过去式，不是过去分词——air 的过去式 = aired，过去分词也是 aired，两个形式一样，但它们在不同的时态结构里扮演不同的角色。

  3. **时间状语的「位置」** — 一般过去时句子里，时间状语通常放在**句末**——这是英语简单陈述句语序规则（第 1 课学过的「时间在最后」）。本课 12 组操练里，所有时间都统一放句末：*I cleaned my shoes **last night**.* / *I opened the window **an hour ago**.* / *I sharpened my pencil **a minute ago**.* 这种「主 + 谓 + 宾 + 时间」的顺序，正是本册第 1 课打下的语序地基。

  4. **过去式 -ed 的三种读音** — 本课 12 个动词全是规则动词，过去式 / 过去分词直接加 -ed。但读法分三种：① **/d/**（元音或浊辅音后）—— *aired*, *cleaned*, *opened*, *sharpened*, *turned*, *boiled*, *emptied*, *answered*；② **/t/**（清辅音后）—— *asked*, *washed*, *walked*；③ **/ɪd/**（t 或 d 后）—— *painted*, *dusted*。跟读录音时注意这三种发音，尤其是 /ɪd/ 多一个音节（painted = /ˈpeɪntɪd/ 两个音节，不是 /peɪntd/ 一个音节）。

  5. **empty → emptied（y 变 i 加 -ed）** — 动词 empty 以「辅音 + y」结尾，变过去式 / 过去分词时要把 y 改成 i 再加 -ed：*emptied*，不是 *emptyed*。同型的还有：*carry → carried*, *hurry → hurried*, *study → studied*。注意 play 是「元音 + y」→ *played*（直接加 -ed，y 不变——因为 ay 是元音组合）。

  6. **祈使句 vs 现在完成时 vs 一般过去时** — 本课三句话构成一个完整的「指令 → 确认已办 → 说明何时」的对话逻辑链。第一句 *Air the room!* 是祈使句（用动词原形开头，省略主语 You）；第二句 *I've already aired the room.* 是用现在完成时确认「事已办完」；第三句 *I aired the room this morning.* 是用一般过去时补充「何时办的」。日常英语对话里这个三段模式极其高频——学会它，你就掌握了一种完整的「交代 / 汇报」表达方式。
</Callout>

## 3. 关键句型：现在完成时 vs 一般过去时

<Callout type="tip" title="一分钟回顾：两个时态，一条分界线">
  本课的核心语法就是把上一课（第 85 课）学到的现在完成时搬进**句型操练**里，与一般过去时**面对面比较**。第 85 课的重点是 **have been to**（曾经去过），本课的重点扩大到**所有实义动词的现在完成时用法**。

  ### 两个时态的「分工」

  | | 现在完成时 | 一般过去时 |
  |---|---|---|
  | **结构** | have / has + 过去分词 | 动词过去式 |
  | **标志词** | already, just, never, ever, yet | this morning, last night, yesterday, … ago, in 2019 |
  | **回答什么** | 「做过了没有？」（结果） | 「什么时候做的？」（时间点） |
  | **例句** | I've already aired the room. | I aired the room this morning. |

  ### ⚠️ 5 个本课最容易踩的雷区

  1. **有具体过去时间 → 必须用一般过去时**：*I cleaned my shoes **last night**.* ✓ / *I've cleaned my shoes **last night**.* ✗ —— 具体过去时间和现在完成时是水火不容的。记住：last night / yesterday / an hour ago / a minute ago 这些时间词一出现，你只能用过去时。

  2. **already 放在 have/has 和过去分词之间**：*I've **already** dusted the cupboard.* ✓ / *I've dusted the cupboard already.* 口语里虽能听见，但本课练的是 already 的**标准书面位置**——夹在助动词和过去分词正中间。

  3. **规则动词的过去式和过去分词同形，但时态结构不同**：*aired* 既是过去式也是过去分词——但说 *I've aired*（完成时）和 *I aired*（过去时）时，结构、含义、搭配全不同。前者需要 have 做助动词，后者不需要。光看动词本身看不出区别，要看**前面有没有 have/has**。

  4. **-ed 读音三规则别忽视**：说完了写，更要练嘴。① 清辅音后读 /t/（asked, washed, walked）；② 元音 / 浊辅音后读 /d/（aired, cleaned, opened, sharpened, boiled）；③ t / d 后读 /ɪd/（painted, dusted）。/ɪd/ 多一个音节，很多初学者把 *dusted* /ˈdʌstɪd/ 念成 /dʌst/ 就错了。

  5. **empty → emptied（y 变 i）**：以「辅音 + y」结尾的动词（carry, hurry, study, empty），过去式 / 过去分词要 **y → i + ed**。但若是「元音 + y」结尾（play, stay, enjoy）则直接加 -ed，y 不变。

  ### 一条句子，「做完了」说哪个、「何时做」说哪个

  学完本课，每次你想说「我已经做了某事」，先判断——你只是想告诉别人「事儿办完了」（用现在完成时），还是想同时说明「什么时候办的」（用一般过去时）。**一条分界线就是有没有具体过去时间**。有，就用过去时；没有，或者带了 already / just / never 这些词，就用现在完成时。
</Callout>

## 8. 过去式 -ed 发音练习 Pronunciation of -ed

<Callout type="tip" title="一分钟回顾：-ed 三种读音，三条规则">
  本课 12 个动词全是规则动词，过去式 / 过去分词都是加 -ed。但读法分三类——取决于动词原形最后一个音：

  | 读音 | 条件 | 本课例词 |
  |---|---|---|
  | **/d/** | 元音 或 浊辅音后 | aired, cleaned, opened, sharpened, turned, boiled, emptied |
  | **/t/** | 清辅音后 | asked, washed, walked |
  | **/ɪd/** | /t/ 或 /d/ 后 | painted, dusted |

  关键：**/ɪd/** 比 /d/ 和 /t/ 多一个音节。painted = /ˈpeɪn.tɪd/（两个音节），dusted = /ˈdʌs.tɪd/（两个音节）。很多人把 dusted 错读成一个音节 /dʌst/——那就把过去式和原形 dust 读混了。读完本课，把 12 个动词的过去式各念 3 遍，体会三种读音的舌头位置。
</Callout>

## 11. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节 SayIt 的三个句子各跟读 5 遍。重点练 **I've already ...** 的连读——*I've* 轻而快（/aɪv/），*already* 重音在第二音节 *-rea-*（/ɔːlˈredi/），整个短语一口气说完。再练第二句过去时的收尾调——*I aired it this MORNing.* 句末降调，给一个「事已说完」的结束感。

  - **替换操练 (substitution drill)**：用手挡住本课 12 组操练的回答部分，看着祈使指令和时间提示，自己先说出两句话，再对照检查。每天练一轮，直到「祈使句 → 完成时 → 过去时」的转换不再需要思考。

  - **-ed 发音三组过关**：把本课 12 个动词的过去式分成三组读——
    - /d/ 组：aired, cleaned, opened, sharpened, turned, boiled, emptied
    - /t/ 组：asked, washed, walked
    - /ɪd/ 组：painted, dusted
    每组念 5 遍。特别注意 /ɪd/ 组的 painted 和 dusted —— 两个音节，别吞成单音节。可以录音对比，听自己的发音和教材录音差别在哪。

  - **我家今天做了啥？** — 合上课本，用本课的句型把你今天已经做完的 5 件事说出来——
    1. *I've already made my bed. I made it this morning.*
    2. *I've already had breakfast. I had it at 7:30.*
    3. *I've already read my book. I read it after lunch.*
    4. *I've already washed my face. I washed it ten minutes ago.*
    5. *I've already finished my homework. I finished it an hour ago.*

  - **时态敏感度训练**：从现在开始，你每次想说「我做了某事」，在脑海里同时生成两句——一句完成时（强调结果），一句过去时（带上时间）。这个习惯养成了，英语时态就再也不会混了。本课是本册必修的一个里程碑——从现在起，你的英语体系里多了 **现在完成时** 这个维度。接下来几课会继续在它上面砌砖（have been to / have gone to、现在完成时 + yet、不规则过去分词……），把这块基石踩实。

  - **听写练习**：听录音，把本课 12 组操练中的 6 组（自选 6 组）的问答默写下来，写完后对照书本核对拼写，重点检查 **emptied（不是 emptyed）、typed（不是 typeed）、dusted（/ɪd/ 别忘了 e）**。
</Callout>
