<Callout type="info" title="Listen first 听前思考">
  上一课（Lesson 21），丈夫请简帮他拿一本书——简连问了两次 *"This one?"* 才找到那本红的。为什么她要多问那几次？因为书架上不止一本！当眼前有好几件东西时，“请给我一个……”是不够的——对方一定会追问一句 **“哪个？”（Which one?）**。

  本课把 Lesson 21 的句型全面升级：用 **6 组对比插图**（每组分左右两个相反状态的物品）操练“**给某人某物**”的**双宾语祈使句**，同时把**宾格代词**（me / him / her / us / them）全部扫一遍。每组图还配了一对**反义形容词**（dirty ⇄ clean, empty ⇄ full, large ⇄ small, blunt ⇄ sharp, old ⇄ new）——这正是 Lesson 20 练过的“形容词反义配对”的延续。本课把它们拧在一起：**怎么请人递东西 → 怎么问哪一个 → 怎么用形容词描述你要的那个。**

  *Listen to the tape then answer the questions.* **听录音，然后回答问题。** 带着耳朵仔细听——每组图各配一段简短对话：先听清“给谁”用了哪个宾格代词，再听清“哪一个”是用什么形容词区分的。
</Callout>

## The Pattern Drill 句型操练

下面是本课 **6 组替换操练**。每组图的左、右两边各有一个**状态相反**的同类物品（比如左边脏杯子 ⇄ 右边干净的杯子），底下配一段对话：

| 图号 | 物品 | 操练对话 |
|---|---|---|
| ① | cup 杯子 | **Give me** a cup please. — Which one? This **dirty** one? — No, not this dirty one. That **clean** one. |
| ② | glass 玻璃杯 | **Give me** a glass please. — Which one? This **empty** one? — No, not this empty one. That **full** one. |
| ③ | bottle 瓶子 | **Give him** a bottle please. — Which one? This **large** one? — No, not this large one. That **small** one. |
| ④ | knife 刀 | **Give her** a knife please. — Which one? This **blunt** one? — No, not this blunt one. That **sharp** one. |
| ⑤ | fork 叉子（复数） | **Give us** some forks please. — Which ones? These **old** ones? — No, not these old ones. Those **new** ones. |
| ⑥ | spoon 勺子（复数） | **Give them** some spoons please. — Which ones? These **new** ones? — No, not these new ones. Those **old** ones. |

注意三个升级点：
- **第 ①–② 组**用 **me**（给我）；**第 ③ 组**用 **him**（给他）；**第 ④ 组**用 **her**（给她）；**第 ⑤ 组**用 **us**（给我们）；**第 ⑥ 组**用 **them**（给他们）。六个宾格代词全部出场——正好把 Lesson 20 里 *Look at **me/him/her/us/them*** 的宾格体系完整搬过来。
- **第 ⑤–⑥ 组**用的是**复数**（forks / spoons），所以问“哪些”用 **Which ones?**（不是 *Which one?*），回答也用 **these / those**（不是 *this / that*）。
- 每组图的核心句型完全一样，只换 **三个槽位**：人称代词（给谁）、物品名（给什么）、形容词（哪样的）。你练的就是在这个句架里**换词不换架**。

## 课文注释 Notes on the text

<Callout type="info" title="6 个值得停下来嚼一嚼的点">
  1. **双宾语祈使句：Give + 人 + 物 + please** — *Give me a cup please.* 动词 **give** 后面跟 **两个宾语**：第一个是“给谁”（间接宾语，用**宾格代词**），第二个是“给什么”（直接宾语，用**名词**）。语序固定：**Give + 间接宾语（人）+ 直接宾语（物）**。please 放句末（加逗号）让语气礼貌。同型：*Pass me the salt, please.*（递我盐。）/ *Show him the photo, please.*（给他看照片。）/ *Bring her a chair, please.*（给她搬把椅子。）
  
  2. **Which one? ⇄ Which ones?** — 问“哪一个”用 **Which one?**（单数），问“哪些”用 **Which ones?**（复数）。**one / ones** 在这里是 Lesson 21 学过的不定代词，代替前面刚提到的名词——问 *Which one?* 就等于 *Which cup?*（第 ① 组），不用再把 cup 说一遍。同理，*Which ones?* = *Which forks?*（第 ⑤ 组）。**this / that** 指单数（这个 / 那个），**these / those** 指复数（这些 / 那些）。

  3. **宾格代词全套** — 本课和 Lesson 20 一样，把六个人称代词的宾格形式完整操练一遍。回顾一下：
  
     | 主格（做主语） | 宾格（做宾语） |
     |---|---|
     | I 我 | **me** 我 |
     | you 你 | **you** 你 |
     | he 他 | **him** 他 |
     | she 她 | **her** 她 |
     | we 我们 | **us** 我们 |
     | they 他们/她们/它们 | **them** 他们/她们/它们 |
     
     记住：**give / show / pass / bring + 宾格代词**，不能放主格——*Give **me** a cup.* ✓ / *Give **I** a cup.* ✗
  
  4. **some + 复数名词** — 第 ⑤ 组 *Give us **some forks** please.* 和第 ⑥ 组 *Give them **some spoons** please.* 中的 **some** 表示“一些”，后面跟**复数可数名词**。为什么不用 *a fork*？因为这里需要的不止一把叉／勺——是给一桌人用的若干把。some 不指定具体数量，相当于“几把、一些”。对比：单数 *a fork*（一把叉）⇄ 复数 *some forks*（一些叉）。注意 spoon 和 fork 都有两种配对——第 ⑤ 组 forks 是 old ⇄ new（旧⇄新），第 ⑥ 组 spoons 是 new ⇄ old（新⇄旧），反向操练确保你真正掌握了而非机械记忆。

  5. **left 左 ⇄ right 右** — 每组图的左边和右边各有一个物品，对话里用 **this / these** 指近处的（左边先出现的那个），用 **that / those** 指远些的（右边后出现的那个）。这正是 Lesson 10–20 反复练过的“近指 / 远指”套路在本课的应用。
  
  6. **反义形容词配对** — 本课六对形容词反义词延续 Lesson 20 的风格：
     - **dirty**（脏的）⇄ **clean**（干净的）——第 ① 组
     - **empty**（空的）⇄ **full**（满的）——第 ② 组
     - **large**（大的）⇄ **small**（小的）——第 ③ 组
     - **blunt**（钝的）⇄ **sharp**（锋利的、尖的）——第 ④ 组
     - **old**（旧的）⇄ **new**（新的）——第 ⑤ 组 / 第 ⑥ 组

     注意：本课操练表面上在练“递东西”，实际上同时把**形容词作定语修饰 one**（*the clean one / the sharp one*）这一关键语法点也练到位了——形容词放在 one 前面，中间**不加冠词 a/an**，但特指时加 **the**：*the clean one*（那个干净的）、*a clean one*（一个干净的）都可以。
</Callout>

## 3. 关键句型：Give + 双宾语 · 宾格代词 · Which one(s) · 形容词作定语

<Callout type="tip" title="一分钟回顾：四个齿轮咬在一起">
  本课表面上学 6 组“递东西”对话，实际上在练**四件事同时做对**：

  ### ① 双宾语祈使句：Give + 间接宾语（人）+ 直接宾语（物）

  句型骨架：**Give + 宾格代词（给谁）+ a / some + 名词（给什么）+ please.**

  | 句式 | 例句 |
  |---|---|
  | Give + 宾格代词 + a + 单数名词 | *Give **me** a cup please.* |
  | Give + 宾格代词 + some + 复数名词 | *Give **us** some forks please.* |

  语序铁律：**人前物后**——间接宾语（人）必须在直接宾语（物）之前。*Give me a cup.* ✓ / *Give a cup me.* ✗

  ### ② 宾格代词表（全员出列）

  | 主格 | 宾格 | 例句 |
  |---|---|---|
  | I | **me** | Give **me** a cup. |
  | he | **him** | Give **him** a bottle. |
  | she | **her** | Give **her** a knife. |
  | we | **us** | Give **us** some forks. |
  | they | **them** | Give **them** some spoons. |
  | you | **you** | Give **you** a glass.（虽没在本课出现，规则一样） |

  ### ③ Which one? ⇄ Which ones?（问哪一个 / 哪些）

  - 单数物 → **Which one?** — one 代替刚提过的单数名词
  - 复数物 → **Which ones?** — ones 代替刚提过的复数名词
  - 回答格式：**not this / these ... one(s). That / Those ... one(s).**——先否定错的、再肯定对的

  ### ④ 形容词 + one(s) 作名词短语

  **形容词放在 one / ones 前面**修饰它，构成一个名词短语：

  | 短语 | 拆解 |
  |---|---|
  | *the clean **one*** | the + 形容词 + one = 那个干净的（东西） |
  | *this dirty **one*** | this + 形容词 + one = 这个脏的（东西） |
  | *those old **ones*** | those + 形容词 + ones = 那些旧的（东西） |

  特指（“那个 / 那些”）用 **the / this / that / these / those** + 形容词 + one(s)；泛指（“一个 / 一些”）用 **a / an** + 形容词 + one：*a clean one*（一个干净的）。

  ### ⚠️ 5 个本课最容易踩的雷区

  1. **宾格代词不能放在句首作主语**：*Give me a cup.* ✓ / *Me give a cup.* ✗（主语应用 I）
  2. **双宾语语序不能倒**：*Give him a bottle.* ✓ / *Give a bottle him.* ✗
  3. **Which one? 后面要有 one 或名词**：*Which one?* ✓ / *Which?* 虽口语里可能听到，但本课操练的规范说法是带 one / ones
  4. **单复数要一致**：*some forks → Which ones?* ✓ / *some forks → Which one?* ✗
  5. **形容词 + one(s) 中间不加冠词 a/an**（除非是泛指“一个……的”）：*the sharp one*（那把锋利的）✓ / *a sharp one*（一把锋利的）也通（泛指），但 *the a sharp one* ✗
</Callout>

## 4. 难点：give sb. sth. = give sth. to sb. · one(s) 的限定 · 复数同步

<Callout type="info" title="三个容易和已学内容混淆的点">
  ### 1. give sb. sth. ⇄ give sth. to sb.

  本课 *Give me a cup.* 用了双宾语（两个宾语直接挨着），也可以换成 **to 结构**：*Give a cup **to** me.* 意思完全一样。日常口语里双宾语（give me a cup）更常用、更直接。但**如果直接宾语是代词（it / them）**，只能或更倾向于 to 结构：

  - *Give **it** to me.* ✓
  - *Give me it.* 口语偶尔用，但教材推荐前一种

  ### 2. one 只能代替可数名词

  **one / ones 只能代替可数名词**——cup / glass / bottle / knife / fork / spoon 都是可数名词，所以能用 one / ones 代替。不可数名词（water / milk / bread 等）不能用 one / ones。

  ### 3. 复数同步：these/those + ones, some + 复数名词

  第 ⑤–⑥ 组操练了复数全套同步：
  - 问：**Which ones?**（不是 Which one?）
  - 指近：**these** old ones（不是 this old one）
  - 指远：**those** new ones（不是 that new one）
  - 答：**No, not these ... ones. Those ... ones.**

  一整套都要保持复数——一个地方错，整句就不通了。
</Callout>

## 7. 书面练习 Written exercise

<Callout type="info" title="教材原题：Written exercise —— 填空 + 仿写">
  **A. 用适当的宾格代词填空：**

  *Example*: Give ___ a cup. (I) → Give **me** a cup.

  1. Give ___ a glass. (he)
  2. Give ___ a bottle. (she)
  3. Give ___ a knife. (I)
  4. Give ___ some forks. (we)
  5. Give ___ some spoons. (they)

  **B. 仿照例句，写出完整的对话回答。先否定对方猜错的那个，再给出自己要的那个：**

  *Example*: (cup / dirty / clean)
  — Give me a cup please.
  — Which one? This dirty one?
  — No, not this dirty one. That clean one.

  1. (glass / empty / full)
  2. (bottle / large / small) —— 用 him
  3. (knife / blunt / sharp) —— 用 her
</Callout>

  **A:**
  1. Give **him** a glass.
  2. Give **her** a bottle.
  3. Give **me** a knife.
  4. Give **us** some forks.
  5. Give **them** some spoons.

  **B:**
  1. — Give me a glass please. — Which one? This empty one? — No, not this empty one. That full one.
  2. — Give him a bottle please. — Which one? This large one? — No, not this large one. That small one.
  3. — Give her a knife please. — Which one? This blunt one? — No, not this blunt one. That sharp one.

  格式口诀：**that + 反义形容词 + one —— 你否定了 this，正确的那个用 that。**
</Callout>

## 9. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。重点练 ① 双宾语祈使句的节奏——*Give me a cup please.* 中的 *Give me* 口语常连读为 /ˈɡɪmi/；② *Which one?* 的开降调——问句上扬、回答下沉；③ 先否后肯的对比节奏——*No, NOT this ... one. THAT ... one.*——否定部分重读 **not**，肯定部分重读 **that**。

  - **角色扮演**：关上课本，打开上方的 ChatDialog，一人分饰 Mum 和 Tom 两个角色，从第一组 cup 一直演到最后一组 spoons。记熟后换词再演——把 cup 换成 plate（盘子）、knife 换成 chopsticks（筷子）、forks 换成 bowls（碗），把本课的句架用到生活的每一个“递东西”场景里。

  - **造句迁移**：用今天学的 5 个核心结构造你自己的句子——
    1. **Give + 宾格 + 物 + please**：*Give me a pen, please. / Give him the menu, please. / Give her a chair, please.*
    2. **Which one(s)?**：*Which one is yours? / Which ones do you want?*
    3. **形容词 + one**：*I like the blue one. / Do you want the big one or the small one?*
    4. **not ... one. ... one**：*No, not this sharp knife. That blunt one. / No, not these full glasses. Those empty ones.*
    5. **宾格代词全套**：*Look at me. Give him a cup. Show her the photo. Pass us the salt. Bring them some water.*

  - **宾格代词专项记忆**：把六组宾格代词写在小卡片上——
    正面写中文“给我 / 给他 / 给她 / 给我们 / 给他们 / 给它”，背面写英文 **me / him / her / us / them / it**。每天抽卡 2 分钟，看见中文就说出英文宾格。记住：**宾格用在动词或介词后面作宾语**——这个规则覆盖 NCE 所有课文。

  - **双宾语 vs to 结构对比**：把同一句两种说法各说 5 遍，感受区别：
    - *Give me the book. = Give the book to me.*
    - *Pass him the salt. = Pass the salt to him.*
    - *Show her the photo. = Show the photo to her.*
    
    双宾语更口语、更简洁；to 结构更正式、当宾语是代词 it/them 时更常用。

  - **场景迁移**：设计三个不同场景，每个场景都用上本课的全部句型：
    1. **在家（给妹妹拿文具）**：*Give me a pencil please. — Which one? This short one? — No, that long one.*
    2. **在餐厅（让服务员给朋友递东西）**：*Give him a menu please. — Which one? This one? — Yes, please.*
    3. **在办公室（分杯子给大家）**：*Give us some cups please. — Which ones? These large ones? — No, those small ones — they're cleaner.*

  - **升级挑战**：把 Lesson 21 的“拿书”对话和本课的“递东西”对话串起来编一段长对话——一个人要书、要杯子、要刀叉，另一个每次都问 *Which one?*，然后再用形容词 + one 描述他要的那个。练到能自如地把六个宾格代词和六对反义形容词在对话里自然切换。
