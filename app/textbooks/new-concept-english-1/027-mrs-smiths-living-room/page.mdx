## The Text 课文

Mrs. Smith's **living room** is large.

**There is** a **television** in the room. The television is **near** the **window**.

**There are** some **magazines** on the television.

**There is** a table in the room. **There are** some **newspapers** on the table.

**There are** some **armchairs** in the room. The armchairs are near the table.

**There is** a **stereo** in the room. The stereo is near the **door**. **There are** some books on the stereo.

**There are** some **pictures** in the room. The pictures are on the **wall**.

  全文共出现了 **5 个 There is** 和 **6 个 There are**。请你划出每个 There be 后面的名词——看看它是单数（a television / a table / a stereo）还是复数（some magazines / some newspapers / some armchairs / some books / some pictures）？规律一目了然：**be 动词跟着后面的名词走**——后面是单数用 **is**，后面是复数用 **are**。这个规律就叫"**就近原则**"（proximity agreement）。

## 课文注释 Notes on the text

<Callout type="info" title="5 个值得停下来嚼一嚼的点">
  1. **living room** (l.1) — "客厅、起居室"。由 living（生活）+ room（房间）构成。课文中 **Mrs. Smith's living room** = 史密斯太太的客厅。其他房间：*bedroom*（卧室）、*bathroom*（浴室）、*kitchen*（厨房——上一课刚学过）、*dining room*（餐厅）。

  2. **There is ... / There are ...** (全文) — 这是英语最常用的"存在句"（There be 句型），表示"（某处）有（某物）"。上一课（Lesson 25）只用了 **There is + 单数名词**；本课引入复数形式——**There are + 复数名词**。be 动词的形式由紧跟在后面的名词决定：*There **is** a television ...*（单数）/ *There **are** some magazines ...*（复数）。这个规律叫"**就近原则**"（proximity agreement）：be 动词只看离它最近的那个名词是单还是复。例：*There **is** a table and some chairs in the room.*（最近的是 a table，单数，所以用 is。）

  3. **some** (l.4, l.6, l.7, l.10, l.11) — "一些"。**some** 用在**肯定句**中，修饰可数名词复数或不可数名词，表示不确定的"一些"。课文中 *some magazines / some newspapers / some armchairs / some books / some pictures* 全都是"some + 复数名词"。⚠️ 否定句和疑问句中要把 some 换成 **any**：*Are there **any** books on the stereo?* / *There aren't **any** newspapers on the table.*（这个在 Lesson 28 会重点操练。）

  4. **near** (l.3, l.8, l.9) — "靠近、在……附近"，介词。课文中：*near the window*（靠近窗户）、*near the table*（靠近桌子）、*near the door*（靠近门）。同型说法：*near the door* ≈ *by the door* / *next to the door*。三个近义介词的区别：**near** = 在附近（不一定紧挨着）、**by** = 在旁边（较near更近）、**next to** = 紧挨着（最近）。

  5. **on the wall** (l.11) — "在墙上"。表示"在墙的表面上"用介词 **on**——画是挂在墙表面上的，所以 *The pictures are **on** the wall.* 对比：如果是嵌在墙里面的（比如窗户、门、开关），则用 **in**：*The window is **in** the wall.* / *There is a hole **in** the wall.* 同型区分：**on the tree**（长在树上的东西——果实、叶子）/ **in the tree**（外来的、落在树上的东西——鸟、风筝）。
</Callout>

## 3. 关键句型：There is / There are —— 单数 vs. 复数

<Callout type="tip" title="一分钟回顾：There be = 有……（存在）">
  上一课 Lesson 25 只教了 **There is + 单数名词**。本课升一级——房间里不只有一个东西，所以复数来了：

  | 例句 | be动词 | 后面的名词 | 规律 |
  |---|---|---|---|
  | There **is** a television in the room. | is | a television（单数） | 单数 → is |
  | There **are** some magazines on the television. | are | some magazines（复数） | 复数 → are |
  | There **is** a table in the room. | is | a table（单数） | 单数 → is |
  | There **are** some newspapers on the table. | are | some newspapers（复数） | 复数 → are |
  | There **are** some armchairs in the room. | are | some armchairs（复数） | 复数 → are |
  | There **is** a stereo in the room. | is | a stereo（单数） | 单数 → is |

  规律：**be 动词看后面第一个名词**——单数用 is、复数用 are。这就是"就近原则"。

  ### 🔑 some 的用法

  本课第一次出现 **some + 复数名词**：*some magazines / some newspapers / some armchairs / some books / some pictures*。

  | 句型 | 用 some | 用 any |
  |---|---|---|
  | 肯定句 | ✅ *There are **some** books.* | ❌ |
  | 否定句 | ❌ | ✅ *There aren't **any** books.* |
  | 疑问句 | ❌（一般不用） | ✅ *Are there **any** books?* |

  > 铁律：**肯定用 some，否定/疑问用 any。**

  ### ⚠️ 5 个本课最容易踩的雷区

  1. **There are 后面忘记加 -s**：*There are some magazine.* ✗ → *There are some **magazines**.* ✓ 复数名词要加 -s / -es。
  2. **There is / There are 后面有多个名词时，be 只看最近的那个**：*There **is** a book and two pens on the desk.* ✓（最近的是 a book，单数）/ *There **are** two pens and a book on the desk.* ✓（最近的是 two pens，复数）。两种都对——be 由**最近的名词**决定。
  3. **There are 后面不能加 a / an**：*There are **a** books.* ✗ → *There are **some** books.* ✓ a / an 只能用在单数名词前。
  4. **肯定句用 some，否定/疑问改用 any**：*Are there **some** books?* ✗ → *Are there **any** books?* ✓（= 有书吗？）。
  5. **on the wall ≠ in the wall**：画"挂在墙上"用 **on** the wall（表面）；窗户"嵌在墙里"用 **in** the wall（内部）。
</Callout>

## 7. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。本课句子整齐而有节奏，重点练 **There is ...** 和 **There are ...** 的自然切换——There is 轻而快（/ðərɪz/），There are 注意要把 /r/ 音连到后面的元音上（/ðərər/）。另外模仿 *near the window / near the door / on the wall* 的句末降调。
  - **看图说话**：合上课本，想象（或自己画）一个客厅的简图——电视靠窗、桌子在中、扶手椅围桌、音响靠门、画在墙上。然后指着每样东西用英语说出来：先"引入"（There is / There are ...），再"描述"（The ... is / are ...）。注意单数用 is、复数用 are，第一次提用 a / some，第二次提换 the。
  - **造句迁移**：用今天学的核心句型 **There is / There are ...** 描述你自己的房间——
    1. *There is a bed in my room. The bed is big.*
    2. *There is a desk in my room. The desk is near the window.*
    3. *There are some books on the desk. The books are interesting.*
    4. *There is a chair in my room. The chair is near the desk.*
    5. *There are some pictures in my room. The pictures are on the wall.*
    注意：单数 → There is + a/an；复数 → There are + some + 名词-s；第二次提 → the。
  - **some vs. any 练一练**：把课文的肯定句变成一般疑问句——
    1. 课文：*There are some magazines on the television.*
       → 提问：*Are there **any** magazines on the television?*
    2. 课文：*There are some newspapers on the table.*
       → 提问：*Are there **any** newspapers on the table?*
    3. 课文：*There are some books on the stereo.*
       → 提问：*Are there **any** books on the stereo?*
    规则：肯定句 **some** → 疑问句 **any**。自己再各造一组肯定→疑问的对照句。
  - **介词练一练**：用 **near / on / in** 三个介词各造一句——
    1. *The lamp is near the bed.*（near = 在……附近）
    2. *The clock is on the wall.*（on = 在……表面上）
    3. *The window is in the wall.*（in = 在……内部）
    特别注意 **on the wall**（画、钟等挂在表面） vs. **in the wall**（窗户、门等嵌在里面）。
  - **预习 Lesson 28**：下一课（双数课）会用本课的所有名词和 There are 句型做一整课的 **Where are they?（它们在哪里？）** 复数问答操练——**Are there any ...?** / **There are some ... on / near / in the ...**。你可以提前准备：把本课的 5 类复数名词（magazines, newspapers, armchairs, books, pictures）搭配 4 个地点短语（on the television, on the table, near the table, on the stereo, on the wall）做成问答对练熟。
