<Callout type="info" title="Listen first 听前思考">
  上一课（Lesson 43），萨姆和彭妮在厨房里上了一场"找茶叶→找杯子→被催快"的三幕剧——彭妮一句 *Can you make the tea, Sam?*，引出了情态动词 **can** 的肯定、否定和疑问三大句式。但对话里还藏着一个贯穿第 41–44 课的家族句型：**There + be** 的存现句。当萨姆问 *Is there any water in this kettle?*（壶里有水吗？）和 *Where are the cups?*（茶杯在哪儿？），前者用了 **Is there any + 不可数名词**，后者则是复数名词 cups，需要用到 **Are there any ...?** 来提问。

  本课是一节**句型操练课（双数课）**。12 组插图，12 组替换操练——从面包到锤子、从牛奶到茶壶、从报纸到小汽车，每一幅图都在练同一套问题框架：**Is there any + 不可数名词 + 方位？**（Lesson 42 学过）与 **Are there any + 可数名词复数 + 方位？**（本课新学）。回答时，不可数名词用 **some** 代替（*There's some on the table.*），可数名词复数用 **some** 代替并由 **There are** 开头（*There are some behind that box.*）。整套操练的核心目标就一个：**把 Is there any ...? / Are there any ...? 的切换 + some/any 的分工，练到自动反应。**

  *Listen to the tape and answer the questions.* **听录音，然后回答问题。** 每看到一幅图，先判断物品是可数复数还是不可数，再用 *Is there any ...?* 或 *Are there any ...?* 提问，用 *Yes, there is/are.* 回答。做完 12 组操练，你就再也不会把 *Is there any bread?* 和 *Are there any hammers?* 搞混了。
</Callout>

## The Pattern Drills 句型操练

下面是本课 **12 组替换操练**——教材插图编号 70–900。左边 6 组是不可数名词（用 **Is there any ...?**），右边 6 组是可数名词复数（用 **Are there any ...?**）。朗读时注意：不可数名词问句用 **Is there any ...?**（有没有一些……？），答句用 **Yes, there is. There's some ...**。可数名词复数问句用 **Are there any ...?**（有没有一些……？），答句用 **Yes, there are. There are some ...**。

| 90 | — | — | | 90 | **milk** | in front of the door |

| 800 | **cars** | in front of that building | | 800 | — | — |

> 总结：**不可数名词**（bread, milk, soap, water, tea, chocolate, coffee）→ **Is there any ...?** / **可数名词复数**（hammers, newspapers, cups, teapots, cars）→ **Are there any ...?**

### 句型操练五步走

围绕每一幅图，依次练 5 种变法——从不可数的 Is there any 到复数的 Are there any，再到用 some 做简略答语，最后反过来自己造句提问：

**Step 1 · 不可数：Is there any ...?**
- **Q:** Look at number 70. Is there any bread here?
- **A:** *Yes, there is. There's some on the table.*
- **Q:** Look at number 90. Is there any milk here?
- **A:** *Yes, there is. There's some in front of the door.*

**Step 2 · 可数复数：Are there any ...?**
- **Q:** Look at number 80. Are there any hammers here?
- **A:** *Yes, there are. There are some behind that box.*
- **Q:** Look at number 200. Are there any newspapers here?
- **A:** *Yes, there are. There are some behind that vase.*

**Step 3 · 否定的简短回答 No, there isn't/aren't any.**
- **Q:** Look at number 100. Is there any bread on the cupboard?
- **A:** *No, there isn't any bread. There's some soap.*
- **Q:** Look at number 500. Are there any glasses in front of that kettle?
- **A:** *No, there aren't any glasses. There are some cups.*

**Step 4 · some 简略答**
- **Q:** Look at number 400. Is there any tea here?
- **A:** *Yes, there is. There's some in those cups.*
- **Q:** Look at number 700. Are there any teapots here?
- **A:** *Yes, there are. There are some in that cupboard.*

**Step 5 · 自己提问**
- **Q:** Ask about number 600.
- **A:** *Is there any chocolate here? — Yes, there is. There's some behind that book.*
- **Q:** Ask about number 800.
- **A:** *Are there any cars here? — Yes, there are. There are some in front of that building.*

## 课文注释 Notes on the pattern

<Callout type="info" title="7 个值得停下来嚼一嚼的点">
  1. **Is there any ...? vs Are there any ...? — 关键看名词的可数性**——这是本课最核心的语法规则。一张表讲清：

  | 名词类型 | 问句 | 答句 | 例句 |
  |---|---|---|---|
  | **不可数名词** | **Is there any** + 不可数名词? | Yes, **there is**. / No, **there isn't**. | *Is there any bread here? — Yes, there is. There's **some** on the table.* |
  | **可数名词复数** | **Are there any** + 可数名词复数? | Yes, **there are**. / No, **there aren't**. | *Are there any hammers here? — Yes, there are. There are **some** behind that box.* |

  判断口诀：**名词能数"一个两个" → 复数用 Are there（hammers / cups / teapots / cars / newspapers）；名词只论"一些、一点" → 用 Is there（bread / milk / soap / water / tea / chocolate / coffee）。**

  2. **肯定答句：不可数用 There's some，复数用 There are some**——这是对 Lesson 42 的升级。Lesson 42 只学了 *Is there a ...?*（可数单数）和 *Is there any ...?*（不可数），用 one / some 代替名词避免重复。本课新增：复数答句用 **There are some**，不能再写 *There's some cups*（⚠️ 口语中虽然常听到 *There's some cups*，但书面语和考试中要用 **There are some cups**）。

  3. **否定式：There isn't any ... / There aren't any ...**——口诀不变：**否定句 + 不可数 / 复数 → any**。对比三式：

  | 句式 | 不可数 (bread) | 可数复数 (hammers) |
  |---|---|---|
  | 肯定 | There's **some** bread on the table. | There are **some** hammers behind that box. |
  | 否定 | There isn't **any** bread on the table. | There aren't **any** hammers. |
  | 疑问 | Is there **any** bread here? | Are there **any** hammers here? |

  4. **some / any 的分工——全题型总结**——结合 Lesson 41–44 的四课积累，一张总表把 some / any 的所有规则一网打尽：

  | 场景 | 可数单数 | 不可数名词 | 可数名词复数 |
  |---|---|---|---|
  | **肯定句** | a / an | **some** | **some** |
  | **否定句** | a / an（不变） | **any** | **any** |
  | **一般疑问句** | a / an（不变） | **any** | **any** |
  | **建议/邀请式疑问** | a / an | **some** | **some** |

  例句：*Would you like **some** coffee?*（邀请—期待 yes → some）/ *Is there **any** coffee?*（纯事实询问 → any）。

  5. **方位介词复习**——本课 12 组操练集中在 5 个方位介词/短语，都是从 Lesson 41–43 积累下来的：

  | 介词/短语 | 含义 | 本课例句 |
  |---|---|---|
  | **on** | 在……上面（接触表面） | *on the table / on the cupboard* |
  | **in** | 在……里面 | *in that cupboard / in those glasses / in those cups* |
  | **behind** | 在……后面 | *behind that box / behind that vase / behind that book* |
  | **in front of** | 在……前面（物体范围外） | *in front of the door / in front of that kettle / in front of that building* |

  6. **不规则名词复数——本课涉及的 4 种变法**——Written Exercise A 里藏着好几个"变形金刚"：

  | 规则 | 单数 → 复数 | 本课例 |
  |---|---|---|
  | 以 f / fe 结尾 → ves | knife → **knives** / loaf → **loaves** / shelf → **shelves** | knives, loaves, shelves |
  | 以 s / x / sh / ch 结尾 → + es | box → boxes / dish → dishes / bus → buses | boxes, dishes, buses |
  | 规则 + s | hammer → hammers / cup → cups / car → cars | 大部分本课可数复数 |

  7. **表量短语：a loaf of bread 等**——Lesson 41 学过用表量短语把不可数名词"包装"成可数单位。本课 Written Exercise A 第 3 题出现了 **loaves of bread**（loaf 的复数形式——因为 coffee 前面用了 some，暗示后面 loaves 也用复数）。
</Callout>

## 3. 关键句型：Is there any ...? / Are there any ...? —— 不可数 vs 复数全对比

<Callout type="tip" title="一分钟回顾：There be 疑问式的两种面孔 + some/any 铁则">
  本课把第 42 课学的 **Is there any + 不可数名词?** 推进一步，新增 **Are there any + 可数名词复数?**。结合第 42 课的一共三类问法，三张对比表一次吃透：

  ### 一、Three there-be question types

  | 名词类型 | 问句 | 答句（肯定） | 答句（否定） |
  |---|---|---|---|
  | 可数单数 | **Is there a** + 单数名词? | Yes, there is. There's **one** ... | No, there isn't. |
  | 不可数名词 | **Is there any** + 不可数名词? | Yes, there is. There's **some** ... | No, there isn't **any**. |
  | 可数复数 | **Are there any** + 复数名词? | Yes, there are. There are **some** ... | No, there aren't **any**. |

  ### 二、some vs any 终极规则（本课完结点）

  | | 肯定句 ☀️ | 否定句 🌧️ | 疑问句 ❓ |
  |---|---|---|---|
  | 不可数名词前 (bread, milk ...) | **some** | **any** | **any** |
  | 可数复数前 (hammers, cups ...) | **some** | **any** | **any** |
  | 可数单数前 (hammer, cup ...) | **a / an** | **a / an**（不变） | **a / an**（不变） |
  | 建议/邀请式疑问句 | **some** | — | **some** ⚠️ |

  ⚠️ **一个例外**：表示邀请、建议、请求且**期望对方答应**时，疑问句里用 some 而不是 any：
  - *Would you like **some** coffee?*（请喝咖啡——期望你说 yes）✓
  - *Can I have **some** water?*（想要点水——请求）✓
  - *Is there any coffee?*（纯事实询问——不期待特定答案）✓

  ### 三、回答时的替身：one vs some（三种情况）

  | 问句 | 替身词 | 答句 |
  |---|---|---|
  | Is there a ...?（可数单数） | **one** | Yes, there's **one** on the table. |
  | Is there any ...?（不可数） | **some** | Yes, there's **some** on the table. |
  | Are there any ...?（可数复数） | **some** | Yes, there are **some** behind that box. |

  ### ⚠️ 4 个本课最容易踩的雷区

  1. **不可数名词千万别套 Are there**：*Is there any bread?* ✓ / *Are there any bread?* ✗ —— bread 不可数，be 动词只能用 **is**。
  2. **可数复数千万别套 Is there**：*Are there any cups?* ✓ / *Is there any cups?* ✗ —— cups 是复数，be 动词只能用 **are**。
  3. **肯定答句中可数复数用 There are some，不是 There is some**：*There are some cups.* ✓ / *There is some cups.* ✗ —— 复数主语配复数 be 动词。
  4. **f / fe 结尾的名词变复数：f → v + es**（不是直接加 s）——*knife → knives / loaf → loaves / shelf → shelves / wife → wives* —— Written Exercise A 反复考这一点。
</Callout>

## 8. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三组 SayIt 各跟读 3-5 遍。重点练 **Is there any ...?**（升调）和 **Are there any ...?**（升调）两种问句的切换速度——看到不可数名词要条件反射地弹出 *Is there any*，看到复数要弹出 *Are there any*。答句注意节奏：肯定句 *Yes, there is/are.*（降调）+ 补充方位（平整收尾）。

  - **看图说话**：合上课本，凭记忆把 12 组插图从头到尾串讲一遍——从 #70 bread，到 #80 hammers，到 #90 milk……一路到 #900 coffee。不可数的说 *Is there any ...? — Yes, there is. There's some ...*；复数的说 *Are there any ...? — Yes, there are. There are some ...*。12 组下来，**Is there / Are there + some / any** 的语序就定型了。

  - **造句迁移**：用今天学的两类句型各造 3 个句子——家里随便找三个不可数东西（水、米、盐、糖、油……）和三个可数复数东西（书、笔、筷子、杯子……），然后照着课文框架造句：
    1. 不可数：*Is there any rice in the pot? — Yes, there is. There's some in the pot.*
    2. 不可数：*Is there any salt on the table? — No, there isn't any.*
    3. 可数复数：*Are there any books on the shelf? — Yes, there are. There are some on the shelf.*
    4. 可数复数：*Are there any pens in the drawer? — Yes, there are. There are some in the drawer.*

  - **some / any 终极自测**：拿出 6 张便签纸，分别写上 3 个不可数名词（bread, milk, coffee）和 3 个可数复数名词（hammers, cups, cars）。随机抽一张，分别用肯定句、否定句、疑问句各说一遍——例如抽到 cups → *There are some cups on the table. / There aren't any cups. / Are there any cups here?* 抽到 coffee → *There's some coffee on the table. / There isn't any coffee. / Is there any coffee here?* 做到 100% 正确再停。

  - **不规则复数整理**：把本课 Written Exercise A 中需要变形的名词全部整理到一张表上，每个写出"单数 → 复数"并造句：
    - knife → knives：*There are some knives in the drawer.*
    - loaf → loaves：*I can see two loaves of bread on the table.*
    - shelf → shelves：*Are there any shelves in that cupboard?*
    - wife → wives：*Mr. Jones and Mr. Brown are here, but I can't see their wives.*
    - dish → dishes：*There are some dishes in the sink.*
    - bus → buses：*Are there any buses in front of the school?*
    - box → boxes：*There are some boxes behind the door.*

  - **Is there vs Are there 判断训练**：看到以下单词，0.5 秒内判断用 Is there any 还是 Are there any：bread → Is / hammers → Are / milk → Is / newspapers → Are / water → Is / cups → Are / chocolate → Is / teapots → Are / cars → Are / coffee → Is。反复练，直到大脑形成"不可数/复数 → Is/Are"的自动反应。

  - **课程衔接**：本课是 NCE1 There + be 句型系列的**最后一课操练课**。第 41 课学了 There is 肯定句 + 表量短语；第 42 课学了 Is there a ...? / Is there any ...? 的疑问式；第 43 课在对话中综合运用；本课（第 44 课）把 Are there any ...?（可数复数）补齐。至此，**There be 句型的三类疑问式（a / any 不可数 / any 复数）+ some/any 的全套分工作战**已经全部学完。第 45 课 *The boss's letter* 将回归对话体，继续深化 **can** 的用法——同时也会在对话中继续用到 there be 句型，巩固本课的成果。
