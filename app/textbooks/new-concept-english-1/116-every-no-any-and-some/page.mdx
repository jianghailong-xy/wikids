<Callout type="info" title="Listen first 听前思考">
  英语里有一组特别能干的"万能代名词"——它们不说具体是谁、是什么、在哪里，却能让你把话说得**既简洁又自然**。本课把 16 个复合不定代词和副词排成一张四栏对照表：**every-**（每一）、**no-**（无）、**any-**（任何 / 若干）、**some-**（某 / 一些），每栏四个词尾 **-one / -body / -thing / -where**。看懂这张表，你就一口气记住了 16 个高频词。

  **Listen to the tape and answer the questions. 听录音，然后回答问题。** 边听边留意：疑问句和否定句里用的是 **any-** 还是 **some-**？说"没有人"用 **no one** 还是 **nobody**？回答"哪儿也没去"用 **nowhere** 还是 **not anywhere**？本课操练就一件事——把 every / no / any / some 四个前缀和四个词尾"拼积木"，拼熟为止。
</Callout>

## The Pattern Drill 句型操练

先看这张总表。**纵向四栏**（Every → No → Any → Some）是"前缀家族"；**横向四行**（-one → -body → -thing → -where）是"词尾系列"。横竖一交叉，16 个词一次到位：

| Every<br/>每一 | No<br/>无 | Any<br/>任何 / 若干 | Some<br/>某 / 一些 |
|---|---|---|---|
| **Everyone** 每人 | **No one** 没有人 | **Anyone** 任何人 | **Someone** 某人 |
| **Everybody** 每人 | **Nobody** 没有人 | **Anybody** 任何人 | **Somebody** 某人 |
| **Everything** 一切 | **Nothing** 没有东西 | **Anything** 任何东西 | **Something** 某物 |
| **Everywhere** 到处 | **Nowhere** 无处 | **Anywhere** 任何地方 | **Somewhere** 某处 |

- **-one** 和 **-body** 含义完全相同，可互换——*Everyone is asleep.* = *Everybody is asleep.*
- **any-** 系列常用于**疑问句和否定句**；**some-** 系列常用于**肯定句**
- **no-** 系列本身已含否定，**句中不再加 not**

下面 12 组插图例句，每组都是"场景 + 句型"，把上面的词放进真实句子里用一遍：

### Every- 系列：每一

> **Everywhere** — 到处

*I looked for my pen **everywhere**.* 我到处找我的笔。

> **Everyone / Everybody** — 每人、人人

***Everyone** is asleep.* / ***Everybody** is asleep.* 大家都睡着了。

> **Everything** — 一切、每样东西

***Everything** is untidy.* 一切都乱七八糟。

### No- 系列：无、没有

> **No one / Nobody** — 没有人

*There's **no one** at home.* / *There's **nobody** at home.* 家里没有人。

> **Nothing** — 没有东西

*There's **nothing** in this box.* 这个盒子里什么也没有。

> **Nowhere** — 无处

*"Where did you go yesterday?" "**Nowhere**. I stayed at home."* "昨天你去哪儿了？""哪儿也没去。我待在家。"

### Any- 系列：任何（疑问 / 否定句）

> **Anyone / Anybody** — 任何人

*Is there **anyone** at home?* / *Is there **anybody** at home?* 家里有人吗？

> **Anything** — 任何东西

*Is there **anything** in that box?* 那个盒子里有东西吗？

> **Anywhere** — 任何地方（否定句）

*I couldn't find my pen **anywhere**.* 我哪儿也找不到我的笔。

### Some- 系列：某、一些（肯定句）

> **Someone / Somebody** — 某人

*There's **someone** in the garden.* / *There's **somebody** in the garden.* 花园里有人。

> **Something** — 某物

*There's **something** under that chair!* 那把椅子下面有东西！

> **Somewhere** — 某处

*My glasses must be **somewhere**! You're wearing them!* 我的眼镜一定在什么地方！——你正戴着呢！

## 课文注释 Notes on the text

<Callout type="info" title="7 个值得停下来嚼一嚼的点">
  1. **复合不定代词 = 前缀 + 词尾**：把 every / no / any / some 四个前缀和 -one / -body / -thing / -where 四个词尾看作"拼积木"。前缀决定**含义范围**（全称 / 否定 / 任意 / 存在），词尾决定**指代类别**（人 / 人 / 事物 / 地点）。⚠️ **-one 和 -body 意思完全相同**，可互换（Everyone = Everybody, No one = Nobody 等）。
  2. **no- 系列本身已含否定**：*There's **no one** at home.* = *There **isn't** anyone at home.* —— 用 no- 时句中动词仍用**肯定式**，不要再加 not。这是初学者最容易踩的雷：*There isn't no one* ✗（双重否定变"有人"）。同型：*I bought **nothing**.* = *I **didn't** buy **anything**.*
  3. **any- 的两个面孔**：① 疑问句中表"任何 / 有……吗"——*Is there **anything** in that box?*（那个盒子里有东西吗？）② 否定句中表"什么也（不）"——*I couldn't find my pen **anywhere**.*（我哪里都找不到我的笔）⚠️ any- **不用于肯定陈述句**（不说 *I found anything*），肯定句用 some-（*I found something*）。
  4. **some- 用于肯定句**：*There's **someone** in the garden.* / *There's **something** under that chair.* —— some- 表"某…… / 一些……"，一般出现在肯定句中。⚠️ 表示邀请或期待肯定回答的疑问句里也可以用 some-：*Would you like **something** to drink?*（想喝点什么吗？——这是邀请，预期回答 Yes。）
  5. **everywhere / anywhere / nowhere / somewhere 的用法**：这四个 -where 词都是**副词**，直接修饰动词，不需要介词 in / at / to 跟在后面——*I looked **everywhere**.* ✓ / *I looked in everywhere.* ✗。⚠️ 特别注意 **nowhere** 本身就是"什么地方也不 / 哪儿也没去"：*I went **nowhere**.* = *I **didn't** go **anywhere**.*
  6. **asleep**（本课生词）—— "睡着的"，**只能作表语**（放在 be 动词之后），不能作定语放在名词前：*The baby is **asleep**.* ✓ / *an asleep baby* ✗（应说 *a sleeping baby*）。同型表语形容词：*awake*（醒着的）、*alive*（活着的）、*alone*（独自的）。
  7. **glasses**（本课生词）—— "眼镜"，注意永远用**复数** glasses（一副眼镜也是 glasses，因为两个镜片）。*My glasses **are** on the table.*（动词用 are，不是 is）。另义 glass 单数 = 玻璃 / 玻璃杯；*a glass of water* = 一杯水，与"眼镜"是两个词。
</Callout>

## 11. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3–5 遍。本课句子节奏单一、句型重复度高，重点练**前缀家族的发音**——*every-* /ˈevri/ 两个音节要清晰、*no-* /nəʊ/ 咬住双元音、*any-* /ˈeni/ 像"A 你"、*some-* /sʌm/ 嘴巴放松像"仨姆"。词尾 *-thing* /θɪŋ/ 咬舌尖，*-where* /weə/ 不卷舌。
  - **复述 (retell)**：合上教材，不看表格，凭记忆说出 16 个复合不定代词的四栏清单（Every → No → Any → Some 横向 + -one / -body / -thing / -where 纵向）。说错一个就从头来，直到一口气无差错说出全部 16 个。
  - **造句迁移**：用今天学的 5 个核心结构各造两个你自己的句子——
    1. **肯定句用 some-**：*There's someone in the classroom. / I bought something nice today.*
    2. **疑问句用 any-**：*Did you see anyone at the party? / Is there anything I can do?*
    3. **否定句用 any-**：*I didn't go anywhere last weekend. / He couldn't find anybody to help.*
    4. **用 no- 词替代 not ... any-**：*I did nothing yesterday.* = *I didn't do anything yesterday.* / *She went nowhere.* = *She didn't go anywhere.*
    5. **Everyone + 单数动词**：*Everyone likes the film. / Is everybody here?*
  - **防坑自查**：下面三个是本课最高频的错误，写完句子回头核对：
    - ❌ *I didn't buy nothing.* → ✓ *I didn't buy anything.* 或 *I bought nothing.*（no- 不配 not）
    - ❌ *Everyone are happy.* → ✓ *Everyone is happy.*（Everyone 是单数）
    - ❌ *I found anything.* → ✓ *I found something.*（肯定句不用 any-）
  - **延伸应用**：下次用英语说"我今天什么也没干"时，忍住不说 *I didn't do anything today.*，试试干净利落的 *I did nothing today.*——本课的核心绝技就是把 didn't ... any- 一刀切换成 no-。你练熟了，说出来的英文立刻少掉三个词、快半拍。
</Callout>
