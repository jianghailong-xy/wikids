  卡罗尔正忙着写一张 **购物单 (shopping list)**。汤姆走过来，一个一个地问：茶叶还有吗？咖啡呢？糖和果酱呢？番茄和土豆呢？肉呢？卡罗尔一一回答——每一句都在盘点家里**有**什么、**没有**什么。问到啤酒和葡萄酒的时候，卡罗尔干脆利落地来了一句：**我不打算去买！** 汤姆最后冒出一句：**我希望你还有钱。**——嗯，钱的事嘛……两个人都不多了。

  **What is Carol not going to buy? 卡罗尔不打算买什么？** 带着这个问题听录音、读课文，重点留意卡罗尔是怎么用 **must（必须）**、**have got（有）** 和 **many / much（许多）** 这三件语法武器，把家里缺什么、该去哪家店、买不买，说得一清二楚。另外，留意 groceries 相关的店铺名称：**grocer's**、**greengrocer's**、**butcher's**——这些是英语里日常购物必会的词。
</Callout>

## The Text 课文

TOM: What are you doing, Carol?

CAROL: **I'm making a shopping list**, Tom.

TOM: What do we need?

CAROL: We **need a lot of things** this week.

CAROL: **I must go to the grocer's**. We **haven't got much tea or coffee**, and we **haven't got any sugar or jam**.

TOM: What about vegetables?

CAROL: I must go to the greengrocer's. We **haven't got many tomatoes**, but we've got **a lot of potatoes**.

CAROL: I must go to the butcher's, too. We **need some meat**. We **haven't got any meat at all**.

TOM: **Have we got any beer and wine?**

CAROL: No, we haven't. And **I'm not going to get any**!

TOM: **I hope that you've got some money.**

CAROL: I haven't got much.

TOM: Well, **I haven't got much either**!

## 课文注释 Notes on the text

<Callout type="info" title="6 个值得停下来嚼一嚼的点">
  1. **make a shopping list** — 写一张购物单。**make** 在这里是制作、写的意思（不是做饭菜——做饭也是 make，但这里是对着一张纸写）。**shopping** 是购物（名词），放在 list 前面作定语。同型：*make a list*（列单子）/ *make a shopping bag* 就变成做一个购物袋了，注意区分。

  2. **must** — 必须。**must + 动词原形**表示必须、不得不做某事，语气比 *have to* 更强，强调说话人觉得非做不可。本课卡罗尔三次说 *I must go to the...*，表示她认为去这些店是当务之急。否定形式是 **mustn't**（禁止），但本课只用了肯定形式。

  3. **have got = have** — 在英式口语中，**have got** 表示有，和 **have** 意思完全一样。《新概念英语》第一册从本课开始大量使用 *have got*。否定是 **haven't got**，疑问是 **Have ... got ...?**。例：*I have got a pen. = I have a pen.* / *We haven't got any tea. = We don't have any tea.*

  4. **many 和 much 都表示许多**，但用法泾渭分明：**many** 修饰**可数名词复数**（many tomatoes 许多番茄）；**much** 修饰**不可数名词**（much tea 许多茶叶、much money 许多钱）。many 和 much 主要用于**疑问句和否定句**中。如果要用于肯定句，一般用 **a lot of**（见下一条）。

  5. **a lot of** — 许多、很多。**a lot of** 既能修饰可数名词、又能修饰不可数名词，而且**一般用于肯定句**。课文里有 *a lot of things*（许多东西——things 可数复数）、*a lot of potatoes*（许多土豆——可数复数）。对比：肯定句 *We've got a lot of potatoes.* → 否定句 *We haven't got many tomatoes.* ——肯定用 a lot of，否定用 many / much，这是最常见的分工。

  6. **at all** — 丝毫、一点、根本。**at all** 放在否定句末尾，起**加强语气**的作用。课文 *We haven't got any meat **at all**.* = 我们一点肉也没有了（强调完全没有）。比较：*I don't like it.*（我不喜欢。）→ *I don't like it at all.*（我一点也不喜欢。——语气更强。）
</Callout>

## 3. 关键句型一：have got = have（表示有）

<Callout type="tip" title="一分钟回顾：英式口语的有——have got">
  从本课起，《新概念英语》第一册大量使用 **have got** 代替 **have** 表有。这是英式口语中非常地道的说法。记住三种形式：

  | 句式 | have got 形式 | 例句 |
  |---|---|---|
  | **肯定句** | have / has got | *We **have got** a lot of potatoes.* |
  | **否定句** | haven't / hasn't got | *We **haven't got** much tea.* |
  | **疑问句** | Have / Has ... got ...? | ***Have** we **got** any beer?* |

  ### ⚠️ 4 个本课最容易踩的雷区

  1. **否定用 haven't got，不是 haven't get**：*We haven't got much tea.* ✓ / *We haven't get much tea.* ✗ —— got 是 get 的过去分词，在 have got 结构里必须用 got。
  2. **疑问句 Have/Has 提前，got 留在原地**：*Have you got any money?* ✓ / *Do you have got any money?* ✗ —— have got 本身就用 have 作助动词，不需要再加 do。
  3. **第三人称单数用 has got**：*She has got a list.* / *He hasn't got much money.* —— has 别写成 have（本课全是第一人称 we/I 所以用的都是 have，但这条规则要记住）。
  4. **have got 只用于有的意思**，不能说 *I have got to go.*（那是 have to go），也不能说 *I have got breakfast.*（那是 have breakfast——吃早饭）。
</Callout>

## 4. 关键句型二：many & much —— 可数与不可数的分水岭

<Callout type="tip" title="一分钟回顾：many 管数得清的，much 管数不清的">
  本课另一条核心语法线是 **many 和 much** 的正确分工。用课文里出现过的名词，一分类就清楚：

  | many + 可数名词复数 | much + 不可数名词 |
  |---|---|
  | many **tomatoes**（番茄——一个一个数得清） | much **tea**（茶叶——数不清颗粒） |
  | many **potatoes**（土豆——一个一个的） | much **coffee**（咖啡——粉末/液体） |
  | many **things**（东西——件件可数） | much **sugar**（糖——颗粒状但视为整体） |
  | | much **jam**（果酱——黏稠的一大罐） |
  | | much **meat**（肉——论块论斤，不可直接数） |
  | | much **money**（钱——抽象不可数） |

  ### 使用场合的口诀

  | 场合 | many / much | a lot of |
  |---|---|---|
  | **肯定句** | 较少用（偏正式） | ✅ 最常用 |
  | **否定句** | ✅ 常用 | 也可用 |
  | **疑问句** | ✅ 常用 | 也可用 |

  课文就是最好的示范：肯定句 *We've got **a lot of** potatoes.*；否定句 *We haven't got **many** tomatoes.* / *We haven't got **much** tea.*

  ### ⚠️ 3 个易错点

  1. **money 不可数**——不能说 *many money* ✗，要说 *much money* 或 *a lot of money*。
  2. bread、rice、water、milk、homework、information、advice 统统不可数——它们都只配 much。
  3. 肯定疑问句（如提议）用 some：*Would you like **some** tea?* ——这里 some 不是 many/much 的问题，而是 some/any 的问题。
</Callout>

## 5. 关键句型三：must —— 表示必须的义务

<Callout type="tip" title="一分钟回顾：must + 动词原形 = 必须做">
  本课卡罗尔连说三次 **I must go to...**——用 **must** 把必须去的语气表达得斩钉截铁。**must** 是情态动词，后面直接跟**动词原形**，没有人称和数的变化。

  | 肯定句 | 否定句 | 疑问句 |
  |---|---|---|
  | I/You/We/They/He/She **must** go. | I **mustn't** (= must not) go. | **Must** I go? |

  ### must 和 have to 的区别

  | | must | have to |
  |---|---|---|
  | **含义** | 说话人觉得必须（主观） | 外部规则要求不得不（客观） |
  | **例句** | *I must go to the grocer's.*（我自己觉得必须去——家里缺东西了） | *I have to wear a uniform at work.*（公司规定必须穿制服） |
  | **否定** | mustn't（禁止——不许） | don't have to（不必——不用） |
  | **⚠️ 区别** | *You mustn't go.* = 你不许去！ | *You don't have to go.* = 你不必去（可以不去）。 |

  ### ⚠️ 2 个本课最容易踩的雷区

  1. **must 后面直接跟动词原形，不加 to**：*I must go.* ✓ / *I must to go.* ✗（这和 have to 正相反——have to 必须有 to）。
  2. **must 没有人称变化**：*I must / He must / They must* 全都一样，不加 -s：*He musts go.* ✗ → *He must go.* ✓
</Callout>

## 10. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3–5 遍。重点练三个音：① *I must go to the grocer's* 一连三个重读词 must–go–grocer's 的节奏；② *a lot of* 连读成 /əˈlɒtəv/ 的英式口音；③ *I haven't got much either!* 句末 either 的 /ˈaɪðə/ 或 /ˈiːðə/ 任选一种，稳定模仿。
  - **角色扮演**：关上书，和对面的 ChatDialog 演一遍整出对话。一人扮 Tom 问，一人扮 Carol 答——特别注意语调：Tom 的疑问句用升调（*Have we got any beer and wine?* ↗），Carol 的 must 用降调（我必须去是坚决的陈述）。
  - **have got 造句**：用 have got 各造 3 个肯定句、否定句和疑问句，说说你家冰箱 / 厨房里有什么、缺什么——
    - 肯定：*I've got some milk. / We've got a lot of eggs. / She's got some bread.*
    - 否定：*I haven't got any cheese. / We haven't got much rice. / He hasn't got any vegetables.*
    - 疑问：*Have you got any orange juice? / Has she got any sugar? / Have we got enough meat?*
  - **many vs much 分类练习**：把下面这些词分成两列——many 列和 much 列：apple、rice、book、water、money、chair、bread、homework、tomato、milk。然后各造一个否定句。
  - **店铺名称收集**：除了本课的 grocer's / greengrocer's / butcher's，英语里还有 **baker's**（面包店）、**chemist's**（药妆店）、**newsagent's**（报刊亭）、**hairdresser's**（理发店）——全是 **'s** 结构。试着用 *I must go to...* 各说一遍。
  - **must vs have to 对比**：用 must（主观必须）和 have to（客观不得不）各造 3 句，体会语气区别。例：*I must go to the supermarket — we've got no food.*（主观感觉必须）vs *I have to go to school at 8 o'clock.*（学校规定，客观要求）。
  - **听写**：听录音，把整段对话默写下来。写完后检查：每一处 **haven't got** 里 got 写全了吗？每一个否定句里用的是 **any** 还是 some？**many** 管的是可数名词吗？**much** 管的是不可数名词吗？
  - **情景迁移**：假设明天你家要来客人，你需要写一张购物单。用本课学到的句型，口头列一遍：*I must go to the ... I haven't got much ... I need a lot of ...* —— 把卡罗尔的台词变成你自己的。
</Callout>
