  上一课（Lesson 41），彭妮的提包里装满了东西——一块奶酪、一条面包、一块肥皂、一块巧克力、一瓶牛奶、一磅糖、半磅咖啡、四分之一磅茶叶……还有一个特别的小铁盒：**一听烟丝**。当山姆问她 *Is that tin of tobacco for me?*（那听烟丝是给我的吗？），彭妮回答得毫不客气——*Well, it's certainly not for me!*（反正肯定不是给我自己的！）。这段对话带出了一对关键句型：**可数名词** 前用 **a / an**，**不可数名词** 前用 **some**（肯定句）或 **any**（疑问 / 否定句）。

  本课是一节**句型操练课（双数课）**。16 幅插图，16 组替换操练——从护照到面包、从勺子到烟丝、从衣柜里的西装到树上的小鸟，每幅图都在练同一套问题框架：**Is there a + 可数名词 + in/on that ...?** 或 **Is there any + 不可数名词 + in/on that ...?**。回答时，可数名词用 **one** 代替（*There's one on the table.*），不可数名词用 **some** 代替（*There's some on the table.*）。整套操练的核心目标就一个：**把 there be 句型的疑问式 + some/any 的分工肌肉记忆练到自动反应。**

  *Listen to the tape and answer the questions.* **听录音，然后回答问题。** 每看到一幅图，先用 *Is there a ...?* 或 *Is there any ...?* 提问，再用 *Yes, there is. There's one/some ...* 回答。做完 16 组操练，你就再也不会把 *Is there a passport?* 和 *Is there any milk?* 搞混了。

### 句型操练五步走

围绕每一幅图，依次练 5 种变法——从肯定 / 否定判断题，到 Is there 提问与回答，再到用 one / some 做简略答语，最后反过来自己造句提问：

**Step 1 · 肯定 / 否定应答**
- **Q:** Look at number 13. Is the passport on the floor?
- **A:** *No, it isn't.*
- **Q:** Is it on the table?
- **A:** *Yes, it is.*

**Step 2 · Is there ...? 完整答**
- **Q:** Look at number 13. Is there a passport here?  
- **A:** *Yes, there is. It's on the table.*
- **Q:** Look at number 14. Is there any milk here?  
- **A:** *Yes, there is. There's some on the table.*

**Step 3 · 纠错否定 There isn't a ... There's a ...**
- **Q:** Look at number 13. Is there a book on the table?
- **A:** *There isn't a book. There's a passport.*
- **Q:** Look at number 14. Is there any bread on the table?
- **A:** *There isn't any bread. There's some milk.*

**Step 4 · one / some 简略答**
- **Q:** Look at number 13. Is there a passport here?
- **A:** *Yes, there's one on the table.*
- **Q:** Look at number 14. Is there any milk here?
- **A:** *Yes, there's some on the table.*

**Step 5 · 自己提问**
- **Q:** Ask about number 13.
- **A:** *Is there a passport on the table?*
- **Q:** Ask about number 14.
- **A:** *Is there any milk on the table?*

## 课文注释 Notes on the text

<Callout type="info" title="7 个值得停下来嚼一嚼的点">
1. **Is there a ... in/on that ...?** — “在那个……中／上有一个……吗？”这是 **there be 句型的一般疑问句**：把 **is 提到 there 前面**即成问句——*There is a passport on the table.* → *Is there a passport on the table?* 回答时先说 **Yes, there is.** 或 **No, there isn't.**。⚠️ 关键在于：和所有 be 动词的疑问句一样，**be 要冲到句首**（there 前面）。

2. **Is there any ... in/on that ...?** — “在那个……中／上有……吗？”当后面的名词是**不可数名词**（milk, bread, tea, tobacco, chocolate, cheese, soap）时，问句用 **any** 而不是 a。对比：*Is there **a** passport on the table?*（passport 可数单数 → 用 a）vs *Is there **any** milk on the table?*（milk 不可数 → 用 any）。

3. **some 与 any 的分工**——这是本课最重要的语法规则。一张表讲清：

| | 肯定句 | 否定句 | 一般疑问句 |
|---|---|---|---|
| 可数单数 | **a / an** | a / an（不变） | a / an（不变） |
| 不可数名词 | **some** | **any** | **any** |

课文实例：*There's **some** milk on the table.*（肯定 → some） / *There isn't **any** bread on the table.*（否定 → any） / *Is there **any** milk on the table?*（疑问 → any）。⚠️ 一个例外：表示建议、请求或希望得到肯定回答的疑问句，仍用 some：*Would you like **some** coffee?*（请喝咖啡——期望对方 say yes）。

4. **回答时用 one 代替可数名词、some 代替不可数名词**——这是一个非常重要的口语习惯：避免重复名词。*Is there a passport on the table? → Yes, there's **one** on the table.*（one = a passport，不重复说 passport）/ *Is there any milk on the table? → Yes, there's **some** on the table.*（some = some milk，不重复说 milk）。

5. **There isn't a ... / There isn't any ... — 纠错否定式**——当对方猜错了物品时，用这个结构纠正：先说 **There isn't a/any** + 错的东西，再说 **There's a/some** + 对的东西。*Is there a book on the table? → There isn't a book. There's a passport.*（你说的书不在，护照在。）不可数同理：*Is there any bread? → There isn't any bread. There's some milk.*

6. **基数词 13–100 的拼写要点**——13–19 都以 **-teen** 结尾（重音在第二个音节），其中 13 thirteen / 15 fifteen 的拼写与基数词 3 three / 5 five 相比有变化；20–90 的整十数都以 **-ty** 结尾，注意 20 twenty（不是 twoty）、30 thirty（不是 threety）、40 **forty**（four → for，少了 u）、50 fifty（five → fif）、80 eighty（eight → eigh，少了一个 t）。

7. **in / on 介词分用**——**in** 表示“在……里面”（三维空间内部），本课中 *in the wardrobe*（在衣柜里面）、*in the tin*（在听里面）；**on** 表示“在……上面”（与表面接触），本课中 *on the table / on the plate / on the chair / on the bookcase / on the radio / on the desk / on the television / on the bridge / on the dressing-table / on the tree*。记住：衣服放进衣柜 → in；桌上放的 → on。
</Callout>

## 3. 关键句型：There be 疑问式 + some & any 分工作战

<Callout type="tip" title="一分钟回顾：there be 句型三式 + some/any 铁则">
本课把第 41 课学的 there be 肯定句推进一步，系统操练**疑问式**和**否定式**，同时把 **some / any** 的分工规则练到条件反射。三张对比表一次吃透：

### 一、There be 句型的三副面孔

| 句式 | 结构 | 可数单数例 | 不可数例 |
|---|---|---|---|
| **肯定** | There is + a/some ... | There is **a** passport on the table. | There is **some** milk on the table. |
| **否定** | There is **not** + a/any ... | There isn't **a** passport on the table. | There isn't **any** milk on the table. |
| **疑问** | **Is** there + a/any ...? | Is there **a** passport on the table? | Is there **any** milk on the table? |

注意到规律了吗？**可数名词单数**前面始终用 **a / an**（肯定、否定、疑问三式都一样）；但**不可数名词**前面——肯定句用 **some**，否定 / 疑问句换成 **any**。这就是本课最核心的铁则。

### 二、some vs any：一张表记一辈子

| | 肯定句 ☀️ | 否定句 🌧️ | 疑问句 ❓ |
|---|---|---|---|
| 用在不可数名词前 | **some** | **any** | **any** |
| 例句 | There's **some** coffee. | There isn't **any** coffee. | Is there **any** coffee? |

⚠️ **一个例外**：表示邀请、建议、请求且**期望对方答应**时，疑问句里用 some 而不是 any：
- *Would you like **some** tea?*（请喝茶——期望你说 yes）✓
- *Can I have **some** water?*（想要点水——请求）✓
- *Is there any tea?*（纯事实询问——不期待特定答案）✓

### 三、回答时的替身：one vs some

| 问句 | 替身词 | 答句 |
|---|---|---|
| Is there a ...?（可数） | **one** | Yes, there's **one** on the table. |
| Is there any ...?（不可数） | **some** | Yes, there's **some** on the table. |

**one** = a + 那个名词（避免重复），**some** = some + 那个不可数名词（同样避免重复）。

### ⚠️ 4 个本课最容易踩的雷区

1. **问句忘了把 is 提前到 there 前面**：*Is there a book on the desk?* ✓ / *There is a book on the desk?* ✗（光靠问号不够，be 必须冲到句首）。
2. **肯定句里把不可数名词前的 some 错写成 any**：*There's **some** coffee.* ✓ / *There's **any** coffee.* ✗ —— any 是“阴天专用”，肯定句是“晴天”→ 用 some。
3. **回答时用 one 还是 some 分不清**：可数单数 → one（*There's one on the table.*）；不可数 → some（*There's some on the table.*）。记法：**可数东西能点“一个两个” → one / 不可数东西只能论“一些” → some**。
4. **可数名词单独出现时忘加 a / an**：*Is there **a** passport on the table?* ✓ / *Is there passport on the table?* ✗ —— 英语里单数可数名词前面一定要有一个“帽子”（a / an / the），不能光头。
</Callout>

## 9. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
- **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。重点练 **Is there a ...?** 和 **Is there any ...?** 两种问句的语调差异——一般疑问句句末用升调 ↗，肯定回答 *Yes, there is.* 用降调 ↘。可数与不可数的切换要练到脱口而出、不假思索。
- **看图说话**：合上课本，凭记忆把 16 幅图从头到尾串讲一遍——每看到 #13 脑子里弹出 *passport → on the table → Is there a passport on the table? Yes, there's one on the table.* 从 13 到 100，按数字顺序一个个过。
- **造句迁移**：用今天学的 5 个结构造自己的句子——
  1. **Is there a ... in/on ...?**（可数）—— *Is there a pen on your desk? — Yes, there is. There's one next to the computer.*
  2. **Is there any ... in/on ...?**（不可数）—— *Is there any water in the fridge? — Yes, there is. There's some in the bottle.*
  3. **There isn't any ... There's some ...**（纠错否定）—— *There isn't any milk in the cup. There's some tea.*
  4. **one 替身代词**—— *I need a pen. Is there one in your bag?*
  5. **some 替身词**—— *Is there any rice? — Yes, there's some in the pot.*
- **some / any 自测**：拿出 5 张便签纸，分别写上 *肯定句 / 否定句 / 一般疑问句 / 建议邀请 / 否定句*，随机抽一张，快速说出不可数名词前该用 some 还是 any。例如抽到“肯定句”→ *There's **some** coffee.*，抽到“一般疑问句”→ *Is there **any** coffee?*，抽到“建议邀请”→ *Would you like **some** coffee?*。做到 100% 正确再停。
- **介词 in / on 实物操练**：在家里走一圈，每看到一个东西就造句——桌上有个杯子 → *There's a cup on the table.* / 冰箱里有些牛奶 → *There's some milk in the fridge.* / 梳妆台上有肥皂吗？→ *Is there any soap on the dressing-table?* 关键规则：**表面接触 → on / 三维内部空间 → in**。特别留意 *on the tree*（长在树上的东西——叶子、果实、鸟停在枝头）vs *in the tree*（钻进树里面的东西，但本课用 on 因为鸟是停在枝头）。
- **数字 13–100 打字练习**：打开一个空白文档，30 秒内靠肌肉记忆打出下面的数字英文：13, 14, 15, 16, 17, 18, 19, 20, 30, 40, 50, 60, 70, 80, 90, 100。拼写错误重来，直到一次全对。
</Callout>
