## The Text 课文

**ANDY:** **Ow!**

**LUCY:** **What's the matter**, Andy?

**ANDY:** I **slipped** and **fell downstairs**.

**LUCY:** **Have you hurt yourself?**

**ANDY:** Yes, I have. **I think that I've hurt my back.**

**LUCY:** **Try and stand up**. Can you stand up? Here. **Let me help you.**

**ANDY:** I'm sorry, Lucy. **I'm afraid that I can't get up.**

**LUCY:** **I think that the doctor had better see you.** I'll phone Dr. Carter.

**LUCY:** **The doctor says that he will come at once.** **I'm sure that you need an X-ray**, Andy.

## 课文注释 Notes on the text

<Callout type="info" title="7 个值得停下来嚼一嚼的点">
  1. **fell downstairs** (l.2) — "从楼梯上摔下来"。**downstairs** 是副词，修饰动词 **fell**，作状语，中间不需要加介词（不是 *fell from downstairs*）。同型：*go downstairs* 下楼 / *come upstairs* 上楼 / *fell off the bike* 从自行车上摔下来。
  2. **Try and stand up.** (l.5) — "试着站起来。"英语中常用 **and** 把两个动词连在一起，表示前一个动作的目的，常用于鼓励某种动作。这种 *try and + 动词原形* 相当于 *try to + 动词原形*。同型：*Come upstairs and see it.*（第13课）/ *Open the window and air the room.*
  3. **Here.** (l.5) — 这里是**感叹词**，意思是"来"或"喂"，用来引起别人注意、或递东西给人。课文里露西伸手去搀扶安迪时说的 *Here.* 就是一种"来吧，我来帮你"的招呼。同型：*Here, let me carry that for you.*（喂，让我帮你拿那个。）
  4. **Let me help you.** (l.5) — "让我来帮你。"动词 **let** 有"允许、让"的意思，后面要用**不带 to 的动词不定式**（即动词原形），不能写成 *Let me to help you.*。同型：*Let me see.* / *Let him come in.* / *Let's go.*
  5. **The doctor says that he will come at once.** (l.8) — "医生说他马上就来。"这是本课的核心语法——**间接引语 / 宾语从句**。把别人说的话转述给第三个人时，**不用引号**，而用 **that 引导的从句**把原话转述出来。注意引述动词 says 是**现在时**，后面的从句保持原话的时态（*will come* 不变）。本课还有三处带 that 的宾语从句（见下方 §3 关键句型）。
  6. **get up** (l.6) — "站起来"。本课 *I can't get up* = 我站不起来。⚠️ 注意 *get up* 还有一个更常见的意思——**"起床"**：*I usually get up at seven.*（我通常七点起床。）具体是"站立"还是"起床"，要看上下文。
  7. **had better + 动词原形** (l.7) — "最好（做某事）"，用来提建议，语气比 *should* 更强、更急迫。课文 *the doctor had better see you* = 最好是让医生看看你。注意 **had better 后面也是用不带 to 的动词原形**，且口语中常缩写为 *'d better*。同型：*You'd better stay in bed.* / *I'd better call an ambulance.*
</Callout>

## 3. 关键句型：宾语从句（1）—— that 从句

<Callout type="tip" title="一分钟回顾：用 that 把别人的话「装进句子里」">
  本课是 NCE1 **第一次正式引入宾语从句**（Object Clause）。你想告诉别人"某个人说了 / 想了 / 觉得什么"，就把那个"什么"用一个 **that 引导的从句**挂在动词后面，充当宾语。

  ### 公式
  > **主语 + 转述动词（say / think / believe / know / be afraid / be sure） + (that) + 从句**

  ### 课文里的 4 个宾语从句（全部用现在时转述，that 都没有省略）

  | 谁说的 | 转述句 | 从句内容 |
  |---|---|---|
  | Andy | I **think that** I've hurt my back. | "我伤了背"（自己的推测） |
  | Andy | I **'m afraid that** I can't get up. | "我站不起来"（担心） |
  | Lucy | I **think that** the doctor had better see you. | "医生最好看看你"（建议） |
  | Lucy | The doctor **says that** he will come at once. | "医生马上来"（转述他人原话） |
  | Lucy | I **'m sure that** you need an X-ray. | "你需要拍片"（确信） |

  ### ⚠️ 5 个本课最容易踩的雷区

  1. **转述动词是现在时，从句的时态不变**：*The doctor **says** that he **will come** at once.*（不能用 *would come*——would come 是转述过去说的话时才用。）
  2. **口语里 that 可以省，但初学者建议保留**：*I think (that) I've hurt my back.* 都对，但保留 that 能让从句的起点一目了然。
  3. **be afraid / be sure 后面接从句，也要加 that**：*I'm afraid that ...* / *I'm sure that ...*——这些是"描写感情的形容词 + that 从句"，that 同样可省，但本课都保留了。
  4. **say 和 tell 别弄混**：*The doctor **says** that he will come.* ✓ / *The doctor **tells** that he will come.* ✗——tell 要带"告诉谁"（间接宾语）：*The doctor tells **me** that he will come.*
  5. **中文习惯加"说 / 觉得"，英文里 that 从句只用一个转述动词**：不会写成 *I think that I've hurt my back that I can't stand up.*——一个主句只带一个 that 从句。
</Callout>

## 4. 难点：had better · at once · get up 的多面含义

<Callout type="info" title="三个常用但容易用岔的表达">
  **1. had better = 最好 / 应该（语气比 should 更强、更急迫）**

  *the doctor had better see you* = 最好是让医生看看你（不马上去可能更糟）。
  口语里常缩写成 **'d better**：*You'd better stay in bed.*（你最好卧床。）
  否定是 **had better not**：*You'd better not move.*（你最好别动。）
  ⚠️ 后面只接动词原形，不加 to。

  **2. at once = immediately = 立刻、马上**

  *come at once* = 马上就来。*at once* 只能放句尾（跟动词后面），不能放句首当"马上"用。
  同义：*right away* / *straight away* / *immediately*。

  **3. get up = 站起来 OR 起床**

  本课 *I can't get up* = 我站不起来（上下文：摔伤后躺着）。
  另一个常见义"起床"：*I usually get up at seven.*
  具体是哪一个看上下文——这就是一词多义的趣味所在。
</Callout>

## 11. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。重点练 **Ow!** 的疼痛惊呼（短促有力）、**What's the matter?** 的关切语调（降调疑问），以及带 **that** 的宾语从句的流畅节奏——*I think that …* / *I'm afraid that …* / *The doctor says that …* 每句都要一口气顺下来。
  - **角色扮演**：合上课本，对着上面的对话框，一人分饰两角——Andy 疼得叫、Lucy 关切的语气，从 *Ow!* 一直演到 *You need an X-ray.*。
  - **造句迁移**：用本课 5 个核心结构造你自己的句子——
    1. **I think that + 从句**（我认为……）——*I think that English is interesting.*
    2. **I'm afraid that + 从句**（恐怕……）——*I'm afraid that I'll be late.*
    3. **主语 + says that + 从句**（某人说……）——*My mother says that I should go to bed early.*
    4. **I'm sure that + 从句**（我确信……）——*I'm sure that you will pass the exam.*
    5. **had better + 动词原形**（最好做……）——*You'd better take an umbrella. It's going to rain.*
  - **that 从句转述游戏**：找一段身边的人说的话，用 *He/She says that …* 转述给第三个人——比如："Mom says that dinner is ready." / "The teacher says that we have homework." 这是英语日常交流里最高频的句式之一，从本课开始把它练成肌肉记忆。
  - **一词多义辨析**：*get up*（站起来 / 起床）、*slip*（滑倒 / 溜走 / 下滑）、*back*（背 / 后面）——每词各造两个不同含义的句子，体会上下文如何决定词义。
  - **听写**：听录音，把这 9 句话默写下来，特别注意 was/were 的缩略形式（*I'm, can't, I've, I'll* 等）。
