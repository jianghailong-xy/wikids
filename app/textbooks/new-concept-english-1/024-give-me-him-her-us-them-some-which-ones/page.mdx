  上一课（Lesson 23），丈夫要妻子递杯子——桌上不止一只，妻子连问了两次 *"Which glasses?"*（哪几只杯子？），丈夫才说清楚是 *"The ones on the shelf."*（架子上的那几只）。这里藏着一个关键升级：当眼前的东西是 **复数** 时，问「哪些」要用 **Which ones?**（不是 Which one?），回答也要用 **The ones on/in the ...**（不是 The one on/in the ...）。

  本课把 Lesson 23 的「复数 + 方位」句型全面展开：用 **10 组替换操练插图**，每组左边画着一个人说 *Give me/him/her/us/them some [复数物品] please.*，右边画着另一个人问 *Which ones?*，然后给出方位回答 *The ones on/in the ...*。10 组操练把 **6 个宾格代词**（me / him / her / us / them）和 **10 组物品 + 方位短语** 全部滚一遍——这正是本课唯一的核心任务：**把 give + 宾格代词 + some + 复数名词、Which ones?、The ones + 方位 这一整套对话流程练到脱口而出。**

  *Listen to the tape then answer the questions.* **听录音，然后回答问题。** 带着耳朵仔细听——每组图里「给谁」用的哪个宾格代词，「哪些」指的什么东西，「在哪里」用的是 on 还是 in。
</Callout>

## The Pattern Drill 句型操练

下面是本课 **10 组替换操练**。每组图左半边一个人说 **Give + 宾格代词 + some + 复数物品 + please.**，右半边另一个人先问 **Which ones?**，然后给出方位回答 **The ones on/in the ...**：

| 图号 | 物品 | 宾格代词 | 方位 | 操练对话 |
|---|---|---|---|---|
| ① | pens 钢笔 | **me** | on the desk | Give **me** some pens please. — Which ones? — The ones **on the desk**. |
| ② | ties 领带 | **him** | on the chair | Give **him** some ties please. — Which ones? — The ones **on the chair**. |
| ③ | spoons 勺子 | **her** | on the table | Give **her** some spoons please. — Which ones? — The ones **on the table**. |
| ④ | plates 盘子 | **us** | on the cupboard | Give **us** some plates please. — Which ones? — The ones **on the cupboard**. |
| ⑤ | cigarettes 香烟 | **them** | on the television | Give **them** some cigarettes please. — Which ones? — The ones **on the television**. |
| ⑥ | boxes 盒子 | **me** | on the floor | Give **me** some boxes please. — Which ones? — The ones **on the floor**. |
| ⑦ | bottles 瓶子 | **him** | on the dressing table | Give **him** some bottles please. — Which ones? — The ones **on the dressing table**. |
| ⑧ | books 书 | **her** | on the shelf | Give **her** some books please. — Which ones? — The ones **on the shelf**. |
| ⑨ | magazines 杂志 | **us** | on the bed | Give **us** some magazines please. — Which ones? — The ones **on the bed**. |
| ⑩ | newspapers 报纸 | **them** | on the stereo | Give **them** some newspapers please. — Which ones? — The ones **on the stereo**. |

注意三个升级点：
- **第 ①–⑤ 组**和**第 ⑥–⑩ 组**各覆盖 5 个宾格代词（me, him, her, us, them），每个代词至少出现两次。
- 全部物品都是**复数可数名词**，前面一律用 **some**（不用 a/an）——所以问「哪些」必须用 **Which ones?**（不是 Which one?），回答也用复数 **ones**。
- 每组**三个槽位**在固定句架里轮换：**人称代词**（给谁）→ **物品名**（给什么复数东西）→ **方位**（东西在哪儿）——你练的是在这个句架里**换词不换架**。

## 课文注释 Notes on the text

<Callout type="info" title="5 个值得停下来嚼一嚼的点">
  1. **双宾语祈使句：Give + 宾格代词 + some + 复数名词 + please** — *Give me some pens please.* 动词 **give** 后面跟 **两个宾语**：第一个是「给谁」（间接宾语，**宾格代词**），第二个是「给什么」（直接宾语，**some + 复数名词**）。语序固定：**Give + 人（宾格）+ some + 物（复数）+ please.**。please 放句末，让语气礼貌。同型：*Pass me some glasses, please.* / *Show him some photos, please.*

  2. **Which ones?** — 问「哪些」的固定说法。**ones** 是 **one** 的复数形式，代替前面刚提过的复数名词——问 *Which ones?* 就等于 *Which pens?*（第 ① 组），不用再把 pens 说一遍。对比：
     - 单数物 → **Which one?**（哪一个？） → *The one on the ...*（那个在……的）
     - 复数物 → **Which ones?**（哪些？） → *The ones on/in the ...*（那些在……的）

     这是 Lesson 23（Which glasses?）的直接延续——本课 10 组全是复数，所以全部用 ones。

  3. **The ones + 方位介词短语** — 回答「哪些」时，用 **The ones + on/in + the + 地点名词** 的格式。这里的 **ones** 复指前面要的那个东西，后面的方位短语限定「是哪些」。本课 10 组全部用介词 **on**（在……上面），因为所有物品都在某个平面上——桌子、椅子、地板、架子等等。注意：**the** 不能省——*The ones on the desk.* ✓ / *Ones on desk.* ✗

  4. **some + 复数可数名词** — 本课全部物品都是复数可数名词（pens / ties / spoons / plates / cigarettes / boxes / bottles / books / magazines / newspapers），所以「一些」用 **some**。对比：
     - 单数：*Give me **a** pen.*（给我一支钢笔）
     - 复数：*Give me **some** pens.*（给我一些钢笔）

     *some* 在这里不指定具体数量，相当于「几支、一些」。这与 Lesson 22 的第 ⑤–⑥ 组 *some forks / some spoons* 一脉相承。

  5. **宾格代词轮换操练** — 本课 10 组操练中，5 个宾格代词 **me / him / her / us / them** 各出现了至少一次。这些宾格代词全部来自 Lesson 20（*Look at me/him/her/us/them!*）和 Lesson 22（*Give me/him/her/us/them a ...*）——本课把「give + 宾格」从单数（give ... a ...）升级到复数（give ... some ...），让你在**换物不换架**的过程中巩固整套宾格体系。
</Callout>

## 3. 关键句型：双宾语 + Which ones? + 方位介词短语

<Callout type="tip" title="一分钟回顾：三个零件组装成一句话">
  本课 10 组对话反复操练的是同一个**三段式句架**：

  ### ① 双宾语祈使句：Give + 宾格代词 + some + 复数名词 + please.

  句型骨架：**Give + 宾格代词（给谁）+ some + 复数名词（给什么）+ please.**

  | 句式 | 例句 |
  |---|---|
  | Give + me + some + 复数名词 | Give **me** some **pens** please. |
  | Give + him + some + 复数名词 | Give **him** some **ties** please. |
  | Give + her + some + 复数名词 | Give **her** some **spoons** please. |
  | Give + us + some + 复数名词 | Give **us** some **plates** please. |
  | Give + them + some + 复数名词 | Give **them** some **cigarettes** please. |

  语序铁律：**人前物后**——间接宾语（人）必须在直接宾语（物）之前。*Give me some pens.* ✓ / *Give some pens me.* ✗

  ### ② Which ones?（复数问「哪些」）

  | 单/复数 | 问句 | 例句 |
  |---|---|---|
  | 单数 | **Which one?** | Give me **a pen**. → Which **one**? |
  | 复数 | **Which ones?** | Give me **some pens**. → Which **ones**? |

  本课全是复数，所以一律用 **Which ones?**

  ### ③ The ones + 方位介词短语（回答「在哪儿」）

  格式：**The ones + on/in + the + 地点名词**

  | 物品 | 方位 | 完整回答 |
  |---|---|---|
  | pens | on the desk | The ones **on the desk**. |
  | books | on the shelf | The ones **on the shelf**. |
  | magazines | on the bed | The ones **on the bed**. |

  on = 在……上面（本课 10 组全用 on）；如果东西在「里面」则用 **in**——*The ones **in** the box.*（盒子里的那些）。

  ### ⚠️ 4 个本课最容易踩的雷区

  1. **复数用 ones，不是 one**：*Which **ones**?* ✓ / *Which one?*（问 *some pens*）✗ —— 单复数必须一致
  2. **give 后用宾格，不是主格**：*Give **me** some pens.* ✓ / *Give I some pens.* ✗
  3. **The ones 中 the 不能省**：*The ones on the desk.* ✓ / *Ones on desk.* ✗ —— 特指「那些」必须有 the
  4. **some + 复数名词，不能用 a/an**：*some pens* ✓ / *a pens* ✗ —— a/an 只用于单数
</Callout>

## 4. 难点：on vs in · some vs a · one vs ones · 方位短语的语序

<Callout type="info" title="四个容易和已学内容混淆的点">
  ### 1. on（在……上面）vs in（在……里面）

  本课 10 组全部用 **on**，因为东西都在某个**平面**上（桌子、椅子、地板、架子等）。如果东西在**容器内部**，就用 **in**：
  - *The ones **on** the table.*（桌子上的那些——桌面）
  - *The ones **in** the box.*（盒子里的那些——盒子内部）

  记住：**表面接触用 on，三维内部用 in。**

  ### 2. some（复数/不可数「一些」）vs a/an（单数「一个」）

  | 用法 | 冠词 | 例句 |
  |---|---|---|
  | 单数可数 | **a / an** | Give me **a** pen. |
  | 复数可数 | **some** | Give me **some** pens. |
  | 不可数 | **some** | Give me **some** milk. |

  本课全是复数可数名词，所以一律用 **some**。注意：*some* 也用于不可数名词（water / milk / bread），但本课暂不涉及。

  ### 3. one vs ones —— 全课最核心的区分

  | 单/复数 | 不定代词 | 限定词 | 例句 |
  |---|---|---|---|
  | 单数 | **one** | this / that / the / a | *The **one** on the desk.* |
  | 复数 | **ones** | these / those / the | *The **ones** on the desk.* |

  **one / ones 只能代替可数名词**——不可数名词（milk / water 等）不能用 one / ones。

  ### 4. 方位短语的语序：The ones 在前，方位在后

  中文说「桌子上的那些」，英文说 **The ones on the desk**——顺序正好相反：英文先说出核心词 **the ones**（那些东西），再用 **on the desk**（在桌子上）来限定。
  - 中文语序：桌子上的 + 那些
  - 英文语序：The ones + on the desk
</Callout>

## 7. 书面练习 Written exercise

<Callout type="info" title="教材原题：Written exercise —— 仿写对话">

  2. (her / spoons / on the table)
  3. (us / plates / on the cupboard)
  4. (them / cigarettes / on the television)
  5. (me / boxes / on the floor)
  6. (him / bottles / on the dressing table)
  7. (her / books / on the shelf)
  8. (us / magazines / on the bed)
  9. (them / newspapers / on the stereo)
</Callout>

## 9. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。重点练 ① 双宾语祈使句的节奏——*Give me some pens please.* 把 *Give me* 口语连读为 /ˈɡɪmi/；② *Which ones?* 的开降调——问句上扬、回答下沉；③ 方位短语的重音——*The ones on the DESK.* —— 地点名词加重读。

  - **角色扮演**：关上课本，打开上方的 ChatDialog，一人分饰 Mum 和 Tom 两个角色，从 pens 一直演到 newspapers。记熟后**换词再演**——把 pens 换成 pencils（铅笔）、ties 换成 socks（袜子）、spoons 换成 bowls（碗），把本课的句架用到生活的每一个「找东西递东西」场景里。

  - **造句迁移**：用今天学的 4 个核心结构造你自己的句子——
    1. **Give + 宾格 + some + 复数物 + please**：*Give me some pencils, please. / Give him some socks, please. / Give her some flowers, please.*
    2. **Which ones?**：*Which ones are yours? / Which ones do you want?*
    3. **The ones on/in the ...**：*The ones in the drawer. / The ones on the sofa. / The ones under the chair.*
    4. **全套三段式**：*Give us some cups please. — Which ones? — The ones on the kitchen table.*

  - **on vs in 专项练**：各造 5 个 on 句子和 5 个 in 句子，体会区别：
    - on（平面接触）：*on the desk / on the table / on the floor / on the shelf / on the wall*
    - in（三维内部）：*in the box / in the drawer / in the cupboard / in the bag / in the room*

  - **宾格代词全套默写**：把 Lesson 20 学过的 6 个宾格代词（me / him / her / us / them / it）每天默一遍——正面写中文「给我 / 给他 / 给她 / 给我们 / 给他们」，背面写英文。记住：**宾格用在动词或介词后面作宾语**。

  - **场景迁移**：设计三个不同场景，每个都用上本课的三段式对话：
    1. **在教室（找文具）**：*Give me some pencils please. — Which ones? — The ones on the teacher's desk.*
    2. **在厨房（分餐具）**：*Give us some cups please. — Which ones? — The ones on the top shelf.*
    3. **在办公室（找文件）**：*Give him some papers please. — Which ones? — The ones on your desk.*

  - **升级挑战**：把 Lesson 23 的 *Which glasses?* 对话和本课的 10 组操练串起来——一个人要杯子、要钢笔、要书、要杂志，另一个每次都先问 *Which ones?* 再确认方位。练到能自如地在 go/come + 宾格、give + 宾格、look at + 宾格之间自然切换，把 Lesson 20–24 五课的核心结构全部打通。
