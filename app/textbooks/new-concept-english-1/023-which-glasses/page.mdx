</Callout>

## 课文注释 Notes on the text

<Callout type="info" title="4 个值得停下来嚼一嚼的点">
  1. **Give me some glasses please, Jane.** — 「请给我几只杯子，简。」 和第 21 课 *Give me a book please.* 是同一句型，但这里宾语从 **a book**（一本）变成了 **some glasses**（几只）。祈使句以动词原形 **Give** 开头，后接双宾语——间接宾语 **me**（给谁）和直接宾语 **some glasses**（给什么）。**some** 用在复数名词前，表示「一些、几个」，不强调具体数量。对比：*a glass* 一只杯子 / *some glasses* 几只杯子。

  2. **Which glasses?** — 「哪几只杯子？」 和 L21 的 *Which book?* 同一句型，但 **glasses** 是复数。**Which** 后面一定要跟一个名词（或 one/ones），用来从一组东西里做选择——这里简不知道丈夫要的是柜子里的哪几只杯子。

  3. **The ones on the shelf.** — 「架子上的那几只。」 这是本课最关键的一句话，拆开看三层：
     - **ones**：one 的复数形式，代替前面刚提过的 **glasses**（复数），避免重复说 *The glasses on the shelf.*
     - **on the shelf**：介词短语作定语，放在 the ones 后面，限定「哪几只」——是**架子上的**那几只，不是桌上的。
     - 这个结构极其好用：**the one(s) + 介词短语** 就能精确描述「哪一个 / 哪一些」。例如：*The one in the box.*（盒子里的那个。）/ *The ones under the table.*（桌子下面的那些。）

  4. **not those** — 「不是那些。」 **those** 是 that 的复数形式，对应近指的 **these**（this 的复数）。这句是 *No, not those glasses.* 的省略——口语里用 those 直接代替 those glasses，省得重复。对比：单数 *not that one*（L21）→ 复数 *not those*（本课）。
</Callout>

## 3. 关键句型：复数祈使句 · Which + 复数名词 · ones 加介词短语

<Callout type="tip" title="一分钟回顾：同一个骨架，从单数升级到复数">
  本课和 L21 共用一套对话骨架。把两课放在一块看，单复数的转换一目了然：

  | L21 Which book?（单数） | L23 Which glasses?（复数） |
  |---|---|
  | Give me **a** book, please. | Give me **some** glasses, please. |
  | Which book? | Which glasses? |
  | This **one**? | These glasses? / These? |
  | No, not that **one**. | No, not **those**. |
  | The red **one**. | The **ones on the shelf**. |
  | This **one**? | These? |
  | Yes, please. | Yes, please. |
  | Here you are. | Here you are. |

  ### 1. 复数祈使句：Give me some ...

  祈使句结构不变，但宾语从「一个」变「几个」时，用 **some + 复数名词**：

  | 单数 | 复数 |
  |---|---|
  | *Give me **a glass**.* | *Give me **some glasses**.* |
  | *Pass me **a pen**.* | *Pass me **some pens**.* |
  | *Show me **a book**.* | *Show me **some books**.* |

  ### 2. ones = one 的复数：代替复数名词

  **one**（单数）→ **ones**（复数）。用法完全一样：代替前面刚提过的名词，避免重复。

  | 单数 | 复数 |
  |---|---|
  | *This **one**?* （代替 a glass） | *These **ones**?* （代替 glasses） |
  | *Not that **one**.* | *Not **those**. / Not those **ones**.* |
  | *The red **one**.* | *The red **ones**.* |
  | *The **one** in the box.* | *The **ones** in the box.* |

  ### 3. one/ones + 介词短语：一口气说清「哪一个 / 哪一些」

  本课最重要的突破：**one/ones 后面可以直接加介词短语来精确定位**——

  | the one(s) + 介词短语 | 含义 |
  |---|---|
  | *The ones **on the shelf**.* | 架子上的那几只。 |
  | *The one **in the box**.* | 盒子里的那个。 |
  | *The ones **under the table**.* | 桌子下面的那些。 |
  | *The one **behind the door**.* | 门后面的那个。 |
  | *The ones **beside the cup**.* | 杯子旁边的那些。 |

  这个结构极其实用——以后问「哪个？」，不用再说一长串，**The one/ones + 介词短语** 就够了。

  ### ⚠️ 4 个本课最容易踩的雷区

  1. **some 不要和 a 搞混**：*Give me **a** glass.*（一只杯子）✓ / *Give me **some** glasses.*（几只杯子）✓ / *Give me **a** glasses.* ✗（a 后面只能跟单数名词）。
  2. **Which 后面跟复数名词不加 s 的陷阱**：*Which **glasses**?* ✓ —— which 后面跟的是复数名词 glasses，which 本身不加 s。不要写成 *Whiches glasses?* ✗。
  3. **one vs ones：单复数要对上**：代替复数名词 glasses 用 **ones**，不能因为看见 one 就只写 one。*The **ones** on the shelf.* ✓ / *The **one** on the shelf.*（如果指多只杯子）✗。
  4. **those 已经是复数代词，不需要再在后面加 ones**：*Not **those**.* ✓（those 直接代替 those glasses）/ *Not **those ones**.* 口语可接受但略显冗余，教材课文只用 *those*。
</Callout>

## 4. 难点：单数 one vs 复数 ones · some vs a · these vs those · 介词 on

<Callout type="info" title="四个一碰就错的地方，一次讲清">
  ### one vs ones：单复数切换表

  | 指代 | 单数 | 复数 |
  |---|---|---|
  | 近指「这个 / 这些」 | **this one** | **these (ones)** |
  | 远指「那个 / 那些」 | **that one** | **those (ones)** |
  | 定语「红的那个 / 那些」 | **the red one** | **the red ones** |
  | + 介词短语「桌上的」 | **the one on the table** | **the ones on the table** |

  ⚠️ 注意：**these ones / those ones** 口语里常说，但课文里只用 **these / those** 直接代替复数名词，更简洁。

  ### some（几个）vs a / an（一个）

  | 数量 | 限定词 | 示例 |
  |---|---|---|
  | 一个（单数） | **a / an** | *a glass* / *an apple* |
  | 几个 / 一些（复数） | **some** | *some glasses* / *some apples* |
  | 不确定数量（不可数） | **some** | *some water* / *some milk* |

  口诀：**「一个用 a，多个用 some。」**

  ### these（这些）vs those（那些）

  | 距离 | 单数 | 复数 |
  |---|---|---|
  | 近（手边 / 眼前） | **this** | **these** |
  | 远（那边 / 架子上） | **that** | **those** |

  课文里简第一次拿给丈夫看的是 **these**（手边的），丈夫说 *No, not **those**.*——他不要眼前的那些，要的是**架子上的那些**（远处的、没在手里的），所以用 those。

  ### 介词 on：在……上面（接触表面）

  **on** = 在……的表面上，有接触。这是 NCE1 遇到的第一个表方位的介词：

  | 例子 | 含义 |
  |---|---|
  | *on the shelf* | 在架子上 |
  | *on the table* | 在桌子上 |
  | *on the desk* | 在书桌上 |
  | *on the floor* | 在地板上 |
  | *on the wall* | 在墙上（挂在墙面上） |

  以后还会学 **in**（在……里面，如 *in the cupboard* 在橱柜里）、**under**（在……下面）等——本课先牢牢记住 **on**。
</Callout>

## 9. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。重点练 *Give me some glasses please, Jane.* 的自然节奏（*some glasses* 的 /s/ 连读）、*The ones on the shelf.* 中 on 的弱读，以及 *Here you are.* 递东西时的语调。
  - **角色扮演**：合上课本，对着上面的对话框，一人分饰两角，从第一句演到最后一句。记熟后**把整段对话从单数切换到复数来回练**——先按课文演 L23（复数），再把 glasses 换成 glass、ones 换 one、these 换 this、those 换 that，逆练 L21（单数）。来回各三遍，单复数切换就刻进肌肉记忆了。
  - **造句迁移**：用今天学的四个核心结构各造 3 个句子：
    1. **Give + me + some + 名词**（复数祈使句）——
       *Give me some pens, please.* / *Pass me some books, please.* / *Show me some pictures, please.*
    2. **The one/ones + 介词短语**（精确定位）——
       *The one in the drawer.* / *The ones under the bed.* / *The one behind the door.*
    3. **Which + 名词？**（选择提问）——
       *Which cup?* / *Which shoes?* / *Which bottle?*
    4. **These / Those**（远近指）——
       *These cups are mine. Those are yours.* / *I like these. I don't like those.*
  - **介词 on 专项**：看着房间里的东西，用 *The ... on the ...* 各说 5 句。例：*The book on the desk. / The cup on the table. / The clock on the wall. / The bag on the chair. / The keys on the shelf.*
  - **单复数切换操练**：拿 L21 和 L23 的对话并排对照，大声朗读，体会每一处单数 → 复数的变化。然后自己编一组：
    - 单数版：*Give me a pen. — Which pen? — This one? — No, not that one. The blue one. — This one? — Yes, please. — Here you are. — Thanks.*
    - 复数版：*Give me some pens. — Which pens? — These ones? — No, not those. The blue ones. — These? — Yes, please. — Here you are. — Thanks.*
  - **场景迁移**：在下面三个场景里各用上本课全部句型，练到脱口而出：
    1. 在厨房：*Give me some plates, please. — Which plates? — The ones in the cupboard.*
    2. 在书房：*Give me some books, please. — Which books? — The ones on the desk.*
    3. 在客厅：*Give me some cushions, please. — Which cushions? — The ones on the sofa.*
  - **介词积累**：本课只学了 **on**（在……上面）。提前预习下一课的介词：**in**（在……里面）和 **under**（在……下面），为后续课程做铺垫。
