  一场好戏，一个好座位——本该是完美的夜晚。可坐在 **“我”** 身后的一对年轻男女偏偏 **大声聊个不停**，吵得 **“我”** 连演员的台词都听不清。回头怒视没用，最后 **“我”** 忍无可忍，气呼呼地抱怨了一句。结果那位年轻男子回了一句更绝的话——*“This is a private conversation!”*（这是私人间的谈话！）。明明吵到了别人，却说这是“私人谈话”，这点小小的讽刺正是本课的笑点。

  **Why did the writer complain to the people behind him? 作者为什么要抱怨坐在他身后的那两个人？** 带着这个问题听录音、读课文，重点留意全篇是怎样用 **一连串简单陈述句（simple statements）** 把一件小事讲得清清楚楚的——这正是本册第一课要打的地基：**英语句子的语序（word order）**。
</Callout>

## The Text 课文

Last week I **went to the theatre**. I had **a very good seat**. The play was very interesting. I did not enjoy it. A young man and a young woman were **sitting behind me**. They were **talking loudly**. I got very angry. I could not **hear the actors**. I **turned round**. I looked at the man and the woman angrily. They did not **pay any attention**. In the end, I **could not bear it**. I turned round again. *‘I can't hear a word!’* I said angrily.

*‘It's **none of your business**,’* the young man said rudely. *‘This is **a private conversation**!’*

## 课文注释 Notes on the text

<Callout type="info" title="6 个值得停下来嚼一嚼的点">
  1. **go to the theatre** (l.1) — “去看戏 / 去剧院看演出”。注意这里 theatre 前用定冠词 **the**，*go to the theatre* 是固定说法，泛指“去看戏”这项活动（类似 *go to the cinema* 去看电影）。英式拼 **theatre**，美式拼 *theater*。
  2. **got angry** (l.3-4) — “生气了”。**get + 形容词** 表示“变得……”，强调状态的“变化”。课文 *I got very angry* = 我（变得）非常生气。同型：*get tired / get excited / get ready*。
  3. **turn round** (l.4) — “转过身、回头”。也可写作 **turn around**（美式更常见）。round 在这里是副词。同型：*look round*（环顾四周）/ *come round*（顺便过来）。
  4. **pay attention (to ...)** (l.5) — “注意、留心”。固定搭配，attention 前一般不加冠词；要说“注意某事”用 **pay attention to** sth.。课文 *They did not pay any attention* = 他们丝毫不予理会（否定句中用 any）。
  5. **I could not bear it.** (l.6) — “我无法忍受了。”**bear** 在这里作“忍受、容忍”讲（动词变化 bear–bore–borne）。其中的 **it** 指上文那对男女大声说话、又对“我”的怒视毫不理会这件事。同义说法：*I could not stand it. / I could not put up with it.*
  6. **none of your business** (l.8) — “不关你的事”。**business** 在这里不是“生意”，而是“(与个人有关的)事”。这是一句略带火药味的口语，意思是“别多管闲事”。同型：*mind your own business*（管好你自己的事）。
</Callout>

## 3. 关键句型 Word order in simple statements 简单陈述句的语序

<Callout type="tip" title="一分钟回顾：英语句子是“有座位表”的">
  本课全篇都是 **简单陈述句（simple statements）**——每句只讲“一件事”。课文开篇 *The policeman arrested the thief.*（警察逮捕小偷）和 *The thief arrested the policeman.*（小偷逮捕警察）用同样的词，语序一变，意思全反——这说明 **英语靠语序定句意**。

  一个完整的简单陈述句最多有 **6 个“位置”**，但不一定每个都用上。把课文的句子拆进这张“座位表”，一目了然：

  | 位置 | 成分 | 课文例 |
  |---|---|---|
  | 1 | **主语** Who / Which / What | *I* / *The play* / *A young man and a young woman* |
  | 2 | **谓语** Action | *went* / *was* / *were sitting* / *were talking* |
  | 3 | **宾语 / 表语** Who / Which / What | *a very good seat* / *very interesting* / *it* |
  | 4 | **方式** How | *loudly* |
  | 5 | **地点** Where | *to the theatre* / *behind me* |
  | 6 | **时间** When | *Last week*（**可放句首，也可放句尾**） |

  这正是教材 Exercise A 那张表的还原（顺序：When? / 主语 / Action / 宾语 / How? / Where?）：

  | When? | Who / What? | Action | Who / What? | How? | Where? |
  |---|---|---|---|---|---|
  | Last week | I | went | | | to the theatre |
  | | I | had | a very good seat | | |
  | | The play | was | very interesting | | |
  | | I | did not enjoy | it | | |
  | | A young man and a young woman | were sitting | | | behind me |
  | | They | were talking | | loudly | |

  ### ⚠️ 4 个本课最容易踩的雷区

  1. **方式状语 (How) 别插在“动词和宾语”中间**：*He opened the door **quietly**.* ✓ / *He opened **quietly** the door.* ✗ —— How 通常放在宾语之后。
  2. **时间状语 (When) 只放句首或句尾，不放中间**：*Last week I went to the theatre.* ✓ / *I went to the theatre last week.* ✓ / *I last week went ...* ✗。
  3. **地点在前、时间在后**：当 Where 和 When 都在句尾时，顺序是 **先地点后时间**：*They built a new school **in our village** **last year**.* ✓
  4. **主语和谓语之间不要随便加逗号或插别的成分**：英语简单句的“主 + 谓 + 宾”是骨架，先把骨架摆对，再往 How / Where / When 三个“附加位”里填词。
</Callout>

## 10. 拓展练习 Going further

<Callout type="tip" title="自学者建议">
  - **影子跟读 (shadowing)**：用第 1 节的三个 SayIt 按钮各跟读 3-5 遍。本课句子短、节奏快，重点练**句末的语气**——抱怨句 *I can't hear a word!* 要带点压住火气的重音，结尾 *This is a private conversation!* 那位男子的“理直气壮”要读出反差。
  - **复述 (retell)**：合上课文，用 1 分钟把这件“看戏风波”讲一遍。**三步走**：起因（去看戏、座位好、戏好看）→ 经过（身后男女大声说话 → 听不见演员 → 怒视无效 → 忍不住开口）→ 结局（对方一句“不关你的事，这是私人谈话”）。
  - **造句迁移**：用今天学的 5 个结构造你自己的句子——
    1. *主语 + got + 形容词*（变得……）—— *I got very tired after the long walk.*
    2. *turn round / look at sb. + 副词*（转身、看着某人……地）—— *She turned round and looked at me angrily.*
    3. *not pay any attention (to ...)*（不理会……）—— *He did not pay any attention to the warning.*
    4. *could not bear / stand it*（无法忍受）—— *The noise was so loud that I could not bear it.*
    5. *It's none of your business.*（不关你的事）—— 口语里回敬别人“多管闲事”时用，注意语气。
  - **语序意识**：本课是全册的“地基课”。今后写每一句英文前，先在心里摆一张“座位表”：**谁(主语) → 做什么(谓语) → 对谁/什么(宾语) → 怎样(How) → 在哪(Where) → 何时(When)**。把骨架（主谓宾）摆稳，再往 How / Where / When 三个“附加位”里填词——记住两条铁律：**方式/时间状语别插在动词和宾语中间；地点、时间同现时先地点后时间。** 语序对了，英语句子就立住了。
</Callout>
